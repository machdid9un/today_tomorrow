# 상상 무전기 STT 낱말 사전 v2 (새 밤 줄거리 기준)

> **한 줄 요약:** 아이가 **'말할 법한 대답'**(밤 고르기·용기 주는 말·주문·마음 낱말)을 keyterms에 먼저 넣고, 용의 내레이션 낱말(장소·소품)은 자리가 남을 때만 넣는다. 고유명사(단짝·방해꾼·밤 라벨·얻는 것)는 틀리면 이야기 진행이 끊기므로 keyterms + 보정 사전 양쪽에 둔다.

- 출처: `lib/story/themes.ts`(nights/villain/host/season/world), `lib/story/sttVocab.ts`, `lib/story/sttContext.ts`
- 한도(sttContext.ts 기준): 실시간 ≤ 50개·각 20자 / 배치 ≤ 150개·각 50자·5단어 / 띄어쓰기 제외 **2글자 미만은 자동 제외**
- 실시간 50개 중 **화면 보기(choices) + 아이 이름 + 공통 핵심 14개**가 먼저 들어가므로, 별마다 '실시간 핵심'은 **30개 안쪽**으로 잡았다.

### 6-3. 보정 사전 적용 규칙

1. 어절 단위 완전 일치 또는 `^…$`/띄어쓰기 경계 정규식으로만 치환한다(부분 문자열 치환 금지: '구름' 안의 '구'를 건드리지 않게).

4. `-요` 꼬리(몰라요→몰라)는 뜻이 같을 때만 접고, '싫어요'처럼 거절은 원문도 로그에 남긴다.
5. 밤 고르기 턴에서는 치환 뒤 `nights[].keywords` 포함 여부로 밤을 판정한다(보정이 먼저, 판정이 나중).

---

## 7. 리드가 코드에 넣는 법 (3줄)

1. **keyterms**: `themes.ts`의 각 별 `sttCore`에 위 '실시간 핵심' 목록(단짝·방해꾼·밤 라벨·얻는 것 + 밤별 대답)을 넣고, 나머지는 `sttMore`에 넣는다. `buildSttKeyterms`가 알아서 한 글자(위·비·문·뿅·얍)를 빼고 50/150개에서 자른다.
2. **post-correction**: `sttContext.ts` 옆에 `sttCorrect.ts`를 두고 6장 표를 `Array<[RegExp, string]>` 치환 맵으로 만든다(`new RegExp('(^|\\s)(몽그리|몽글리|몽구리)(?=\\s|$)', 'g')` → `'$1몽글이'`). 긴 패턴 먼저, 아이 이름·collected는 건너뛰기, `/api/transcribe` 결과 → `isLikelySttHallucination` → `correct()` → 밤 판정 순서로 끼운다.
3. **한 글자 낱말**(응·음·왜·위·비·문·뿅·얍·쉿)은 keyterms 대상이 아니라 보정 사전과 `buildSttPrompt`에서만 다룬다. '쉿'·'뿅'처럼 한 글자 정답이 중요한 밤(남색·주문)은 화면 보기(choices)로 그 낱말을 띄워 STT에 힌트를 준다.

### 부록: 소스 코드에서 눈에 띈 점 (수정하지 않음)
- `themes.ts` 물불 `steam_cloud.hook`에 **'타닭이'**(오타) → '타닥이'. TTS가 그대로 읽으면 아이가 그 발음을 따라 할 수 있어 보정 사전에도 '타닭이 → 타닥이'를 넣는 편이 안전.
- 물불 `characters`에는 '김구름'(붙여쓰기), 밤 라벨은 '김 구름'(띄어쓰기). 한쪽으로 통일 권장(본 문서는 라벨 기준 '김 구름').
- 물불 `sttCore`의 '촛불이'는 현재 줄거리에 없는 인물.
