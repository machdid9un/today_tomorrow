상상 무전기 🎙️🌙

화면을 바라보지 않고, 아이의 목소리로 만들어 가는 잠자리 모험. 아이는 자기 모험을 만들고, 부모는 묻지 않고 본다.

상상 무전기는 아이의 발화에 따라 AI가 이야기를 이어 가는 오디오 중심 인터랙티브 동화 웹앱입니다. 대상은 말로 상상을 만들 수 있는 만 4세...만9세 (유치원초등 저학년)이고,
첫 공략은 만 5세...7세입니다. 아이는 화면을 거의 조작하지 않고 핸즈프리 음성 대화로 5~10분 모험을 진행합니다. 부모는 두 가지를 받습니다. 아이가 만든 이야기를 다듬은 동화책, 그리고 아이가 이야기 속에서 고른 것과 한 말을 근거로 한 행동 관찰 리포트입니다. 완성된 회차는 섬으로 저장되고, 다음 회차는 등장인물·물건·사건을 기억합니다.

돈: 결제자는 부모. 가족 구독 월 9,900원(가설). 무료 = 주 2화 + 리포트 요약 한 줄 + 동화책 / 유료 = 매일 + 씨앗 + 전체 관찰 리포트. 첫 고객은 설문에 답한 학부모 5명과 그 반 단톡.

하지 않는 것: 학습 주입 X · 진단 X · 캐묻기 X · 중독 설계 X. 스토리 엔진은 이야기만 하고 아이를 분석하지 않습니다. 리포트 생성기는 아이의 행동을 추론하되, 모든 추론에 원본(아이가 한 말·고른 선택)을 근거로 붙이고, 원본이 없는 추론은 쓰지 않습니다.

목표: 개발 3명(역할 1~4 중 3개를 전담, 1개는 시간 남는 사람이 추가 수행) + 비즈니스 1명이 AI 코딩 에이전트로 05:00 기능 동결, 08:00 제출까지 실제로 돌아가는 MVP를 배포·시연합니다.

현실적인 범위: '핸즈프리'는 부모가 시작한 뒤 화면이 켜진 웹앱에서 아이가 매 턴 버튼을 누르지 않고 말하는 방식입니다. 기기 잠금·백그라운드 유지는 보장하지 않습니다. 음성은 VAD → 발화 단위 녹음 → STT → LLM → TTS로 구현하며, 실시간 음성 통화는 만들지 않습니다. 환경변수 VOICE_MODE=handsfree|ptt 하나로 푸시투토크로 즉시 전환 가능해야 합니다. 22:00 피벗 게이트에서 VAD·에코가 안 잡히면 코드 재작성이 아니라 플래그 전환으로 대응합니다.

0. 뼈대 파일 규칙 (협업 필수)

역할 1이 만든 뼈대 파일과 폴더(7장 구조)는 빈 파일 상태에서 각자 나눠 채웁니다.

이름 변경·삭제·이동 금지. 뼈대에 있는 파일과 폴더의 이름·위치는 그대로 둡니다. 에이전트가 "구조를 정리하자"며 옮기거나 합치려 해도 거절합니다.
파일 추가는 허용. 자기 소유 폴더 안에서라면 새 파일·하위 폴더를 만들어도 됩니다(예: app/api/auth/parent-gate/route.ts, lib/story/prompts.ts).
다른 역할 소유 폴더에 파일을 추가해야 하면 먼저 그 담당자에게 말합니다.
뼈대의 이름이 마음에 안 들어도 바꾸지 말고, README의 이름을 따라 씁니다.
package.json, next.config.*, tsconfig.json, app/layout.tsx, types/는 역할 1 승인 없이 수정하지 않습니다.
1. 기술 스택

웹: Next.js App Router + TypeScript + Tailwind CSS
배포: Vercel (HTTPS 필수 — 마이크 권한)
DB / 인증: Supabase PostgreSQL + Supabase Auth (이메일 매직링크, 선택 기능)
음성 입력: 브라우저 마이크 상시 세션 + VAD → 발화 완료 후 STT API 전송
동화 생성: LLM API, 문장 단위 SSE 스트리밍 + 구조화된 턴 결과
음성 출력: TTS API, 문장별 재생 큐 + 짧은 무전기 지직 효과음
협업: GitHub, 기능 브랜치, PR, AI 코딩 에이전트
STT/LLM/TTS 공급자·모델은 20:30까지 확정합니다. 래블업 바우처로 가능한 축부터 확인합니다. 모든 API 키와 Supabase 서비스 롤 키는 서버에서만 사용합니다.

매직링크 주의: Supabase 기본 메일 발송은 시간당 발송 한도가 낮습니다(정확한 값은 프로젝트 설정에서 확인). 심사위원·참가자가 몰리면 메일이 안 갈 수 있으므로, 로그인 없이도 1화 → 2화 → 리포트가 모두 돌아가야 합니다. 로그인은 "다른 기기에서도, 오래 보관"용입니다.

2. 우선순위 (모든 판단의 기준)

P0 — 없으면 데모 불가 (동결 02:00)

게스트 1화 핸즈프리 루프
종료 3조건 (시간·수면 발화·침묵)
턴 SSE 스트리밍 + 문장별 TTS 큐
자동 저장 (턴 기록이 리포트보다 우선)
선택지 버튼 폴백
회차 끝 건네주기 화면 → 보호자 결과 화면
부모 모드 관문(길게 누르기 + 확인 → 서버 발급 부모 토큰). 리포트·원본 API는 부모 토큰 필수
부모 리포트: 요약 + 인용 + 선택 + 근거 붙은 행동 관찰 + 건네볼 한마디 + 내일 예고
게스트 2화 기억 (같은 기기 쿠키로 이어가기, 로그인 불필요)
회차 완료 즉시 섬 카드 1장 생성
심사용 짧은 회차 ?short=1 (3턴)
P1 — 점수 올림 (동결 04:00)

부모 씨앗 저장 (프리셋 5개 + 자유 입력)
동화책 열람 (아이: 듣기 중심 / 부모: 텍스트)
요금제 한 줄 + 사전 신청 (이메일 동의)
매직링크 로그인 + 게스트 세션 귀속 (다른 기기·장기 보관용)
공유 카드 (P1에서 가장 먼저 버릴 후보)
P2 — 안 되면 버림 (동결 05:00)

부모 PIN (관문을 PIN으로 강화: 설정·검증·잠금)
섬 "지도" 레이아웃
에피소드 TTS 다시 듣기
P0가 흔들리면 P1·P2는 손대지 않습니다. 섬은 처음부터 카드 리스트로 만들고, 시간이 남으면 배치만 지도처럼 바꿉니다.

3. 서비스 흐름

A. 처음 방문 (게스트, 로그인 없음)

현실적으로 링크를 처음 여는 사람은 부모이고, 부모가 아이에게 건넵니다. 아이 쪽은 건네받은 순간부터 설정·설명 없이 바로 시작돼야 합니다.

랜딩: 화면 중앙에 큰 무전기 켜기, 우상단에 작게 로그인. 버튼 아래 한 줄: "AI가 아이의 말로 이야기를 만들어요. 목소리는 저장하지 않아요."
버튼 → 브라우저 마이크 권한(부모가 허용) → 게스트 세션 생성 → 모험 화면.
AI가 음성으로 "치익… 여기는 탐험대! 대장님 이름이 뭐예요?" 질문, 아이가 음성으로 답변. 이름·나이 입력 화면은 없습니다.
약 5분 첫 모험 진행 (?short=1이면 3턴).
아이에게 들리는 종료 멘트: "오늘 무전은 여기까지. 내일 또 만나." — 가입·결제 언급 없음.
건네주기 화면: 「엄마 아빠에게 건네주세요」 + 보호자 보기 버튼. 아이 눈앞에 리포트가 바로 뜨지 않게 합니다(특히 글을 읽는 7~9세).
보호자 보기 → 부모 관문 → 보호자 결과 화면: 첫 관찰 리포트 전체 + 동화책 + "내일 2화가 이어져요".
같은 기기에서 다음 날 앱을 열면 게스트 쿠키로 2화가 1화를 이어갑니다. 로그인은 결과 화면 하단의 선택 사항: "다른 기기에서도 보려면 이메일로 링크 받기"(= 매직링크 가입 + 사전 신청 동의 선택).
게스트 규칙: 가입을 강제하지 않습니다. 게스트 세계는 쿠키가 살아 있는 동안 같은 기기에서 이어집니다(만료 기한 명시). 모험 도중 팝업·가입 유도로 아이를 방해하지 않습니다. 가입·결제 CTA는 아이 화면에 절대 나오지 않고, 아이에게 "엄마한테 사달라고 해" 같은 말도 하지 않습니다.

B. 회원가입 / 로그인 (선택)

Supabase Auth 이메일 매직링크 하나. 로그인 비밀번호 없음.
선택 입력: 아이 이름, 나이. 성별·관심사는 받지 않습니다.
한 계정에 부모 모드 / 아이 모드. 아이용 별도 계정은 만들지 않습니다.
