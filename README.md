

# 상상 무전기 🎙️🌙


> **화면을 바라보지 않고, 아이의 목소리로 만들어 가는 잠자리 모험.** 
> 오늘 만든 세계를 기억하고, 내일은 그 세계에 새로운 섬이 생깁니다.


`상상 무전기`는 아이의 발화에 따라 AI가 이야기를 이어 가는 **오디오 중심 인터랙티브 동화 웹앱**입니다. 부모는 하나의 계정에서 아이의 이야기를 살펴보고 다음 이야기의 씨앗을 설정할 수 있습니다. 아이는 화면을 거의 조작하지 않고 **핸즈프리 음성 대화**로 5~10분 동안 모험을 진행합니다. 완성된 회차는 세계관 지도의 **섬**으로 저장되며, 다음 회차에서 등장인물·물건·사건을 기억합니다.


**목표:** 4명이 AI 코딩 에이전트를 활용해 **10시간 이내에 실제로 돌아가는 MVP**를 개발·배포하고 시연합니다.


> **현실적인 범위:** 이번 MVP의 '핸즈프리'는 **부모가 시작한 이후 화면이 켜져 있는 웹앱에서, 아이가 매 턴 버튼을 누르지 않고 말하는 방식**을 의미합니다. 기기를 잠그거나 앱을 백그라운드로 보낸 뒤에도 음성이 유지되는 기능은 보장하지 않습니다. 음성 처리는 `VAD → 발화 단위 녹음 → STT → LLM → TTS`로 구현하며, 실시간 음성-to-음성 통화는 만들지 않습니다.

## 1. 기술 스택


| 영역 | 기술 / 원칙 |
| --- | --- |
| 웹 | **Next.js App Router + TypeScript + Tailwind CSS** |
| 배포 | **Vercel** |
| DB / 인증 | **Supabase PostgreSQL + Supabase Auth** (이메일 매직링크) |
| 음성 입력 | 브라우저 마이크 상시 세션 + **VAD**, 발화 완료 후 **STT API** 전송 |
| 동화 생성 | **LLM API**, 스트리밍 문장 이벤트 및 구조화된 턴 결과 |
| 음성 출력 | **TTS API**, 문장별 재생 큐 + 짧은 무전기 지직 효과음 |
| 협업 | GitHub, 기능 브랜치, Pull Request, AI 코딩 에이전트 |


STT/LLM/TTS 공급자와 모델명은 **개발 시작 1시간 내** 팀이 확정합니다. API 키·Supabase 서비스 권한 키는 반드시 서버 측에서만 사용합니다.

## 2. 서비스 흐름: 게스트 → 회원 → 부모·아이 모드


### A. 처음 방문한 사용자 (로그인 없이 시작)


1. 랜딩 페이지 우측 상단에 작은 **`로그인` / `회원가입`** 버튼을 표시합니다.
2. 화면 중심에 큰 **`나만의 동화 시작하기`** 버튼을 표시합니다.
3. 버튼을 누르면 회원가입 없이 게스트 모험을 시작합니다.
4. AI가 음성으로 **"이름이 뭐야?"**라고 묻고, 아이의 음성 답변을 듣습니다.
5. 아이의 말을 바탕으로 **약 5분**짜리 첫 동화를 진행합니다.
6. 동화가 끝나면 **"다음 이야기를 이어가고 싶으면 부모님께 알려드려!"**라고 안내합니다.
7. 보호자용 화면에서 회원가입을 제안하고, 가입하면 게스트 회차를 해당 계정의 세계관에 연결합니다.


**게스트 규칙:** 첫 체험을 위해 회원가입을 강제하지 않습니다. 게스트 모험은 임시 세션으로 관리하며, 보호자 등록 전에는 장기 보관을 보장하지 않습니다. 체험 도중 회원가입 유도 팝업으로 아이의 이야기를 방해하지 않습니다.


### B. 회원가입 / 로그인


- **인증 방법:** Supabase Auth 이메일 **매직링크** 로그인·가입.
- **선택 입력:** 아이 이름, 나이, 성별, 기본 관심사. 입력하지 않아도 가입 가능하며, 성별 정보는 스토리 생성의 필수 조건으로 사용하지 않습니다.
- **필수 보호 기능:** 아이 모드에서 부모 모드로 돌아갈 때 사용하는 별도의 **부모 비밀번호(PIN)**를 설정합니다.
- **하나의 계정**에 부모·아이 **두 가지 모드**를 제공합니다. 아이용 별도 이메일 계정은 생성하지 않습니다.


> **중요 — 매직링크와 부모 비밀번호는 서로 다릅니다.** 매직링크 인증에는 로그인 비밀번호가 없으므로, '아이 → 부모' 전환용 **별도 4~6자리 부모 PIN**을 설정합니다. PIN은 서버에서 검증하고 해시로 저장하며, 반복 오입력 제한을 둡니다. PIN 없이 프론트엔드 화면만 바꿔 부모 기록에 접근할 수 없게 해야 합니다.


### C. 부모 모드


- **어제의 동화 리포트**: 전날 이야기 요약, 아이가 실제로 한 말·선택의 인용, 조심스러운 관찰 한마디.
- **아이 진단 대신 비진단적 관찰**: 성격·심리 상태를 단정하거나 임상적 진단을 표시하지 않습니다. `오늘 이야기에서는 친구를 돕는 선택을 했어요`처럼 관찰 가능한 사실을 표시합니다.
- **오늘의 동화 요청사항(씨앗)**: 선택형 프리셋 + 자유 입력. 예: `새로운 친구에게 인사하기`, `채소를 먹는 경험`, `우주에 대한 호기심`.
- **원본 열람**: 회차별 아이의 전사 텍스트와 AI 내레이션, 선택 기록.
- **설정**: 아이 프로필, 부모 PIN 관리, 모드 전환.
- **아이 모드로 전환**: 버튼 한 번으로 가능.


### D. 아이 모드


- **세계관 지도**: 완료한 에피소드마다 **섬 하나**가 생깁니다. 해커톤에서는 SVG/CSS 기반의 간단한 섬 카드·지도 표현이면 충분합니다.
- **`오늘의 동화 만들기`**: 핸즈프리 모험 시작.
- **섬 선택**: 해당 에피소드의 `동화책 형태로 다듬어진 글`을 읽고 TTS로 다시 듣습니다.
- **부모 모드로 전환**: 별도의 부모 PIN 입력 화면을 거칩니다.
- **공유 카드**: 에피소드 제목과 섬 비주얼 중심. 아이의 원문·부모 메모 등 비공개 정보는 기본적으로 공개하지 않습니다.

## 3. 음성 모험 핵심 로직


### 회원 모험


```text
부모가 동화 씨앗 설정(선택) → 아이 모드에서 오늘의 동화 시작
 → 이전 에피소드의 세계관 기억 조회
 → AI가 첫 장면을 TTS로 들려줌
 → 마이크 활성화 → VAD로 아이 발화 종료 감지
 → 발화 단위 오디오를 STT로 변환
 → 아이 발화 + 기존 세계관 + 오늘의 씨앗을 스토리 엔진에 전달
 → LLM이 다음 장면을 문장 단위 스트리밍
 → 도착한 문장부터 TTS 큐에 넣어 순서대로 재생
 → 다음 아이 발화 기다림 → 반복
 → 종료 조건 충족 → 자동 저장 / 리포트 / 기억 / 책 문장 생성
 → 다음 날 아이의 지도에 새로운 섬 표시
```


### 종료 조건 (코드와 AI가 함께 제어)


| 조건 | 동작 |
| --- | --- |
| **5~10분** | 5분 이상 진행된 뒤 AI가 자연스러운 결말 타이밍을 제안하면 종료. **10분은 하드 타임아웃**으로 마무리. |
| **아이의 "잘래", "졸려", "이제 잘 거야" 등** | 새 모험을 더 만들지 않고 **짧고 부드러운 마무리 멘트** 후 종료. |
| **1분간 무응답** | 아이가 잠든 것으로 가정해 **조용히 세션 종료**하고 지금까지의 기록 저장. 추가 TTS가 아이를 깨우지 않도록 함. |
| **부모가 수동 종료** | 종료 확인 후 가능한 기록 저장; 예외 상황에서도 유실을 최소화. |


- 무응답 60초 타이머는 **AI 음성 재생이 완전히 끝난 뒤** 또는 마지막 발화 처리가 끝난 뒤 시작합니다. API 대기·재생 중에는 침묵으로 판정하지 않습니다.
- TTS 재생 중 마이크로 AI 자신의 음성이 재인식되지 않도록 입력 처리 상태를 제어합니다. 기기별 에코 제거 효과도 테스트합니다.
- STT 실패, 마이크 권한 거부, VAD 오탐 시 **선택지 버튼 폴백**을 표시합니다. 버튼 사용은 예외 처리이며 정상 경로는 음성만으로 진행합니다.
- **지직 효과음**은 시작·전환 시 짧고 작은 볼륨으로 사용하며, 취침을 방해할 만큼 반복하지 않습니다.
- **지연 목표:** 아이 발화 종료부터 **첫 TTS 소리가 실제 재생될 때까지 5초 이내를 목표**로 측정합니다. 보장치는 아니며 실제 기기와 네트워크에서 로그로 확인합니다.
- 첫 문장 TTS부터 가능한 한 빨리 재생하고, 뒤 문장은 순서가 보장되는 큐에 쌓습니다.


### 게스트 모험과 회원 모험의 차이


| 항목 | 게스트 | 로그인 사용자 |
| --- | --- | --- |
| 시작 | 이름을 **음성으로 질문** | 프로필 이름 활용, 없으면 질문 |
| 시간 | 약 **5분** | **5~10분** |
| 기억 | 임시 세션 | Supabase에 지속 저장 |
| 다음 화 | 종료 후 보호자 가입 유도 | 기존 세계관을 이용해 이어가기 |
| 결과 | 가입 유도와 간단한 미리보기 | 부모 리포트 + 원본 + 섬 생성 |

## 4. AI 기능 세 가지 (3번 담당)


### ① 스토리 엔진


입력: `아이 이름/나이(있다면)`, `관심사`, `부모의 이야기 씨앗`, `지난 세계관 기억`, `현재 회차 대화`, `경과 시간`, `종료 이유`.


출력은 **검증 가능한 턴 구조**로 통일합니다.


```json
{
 "narration": "토토가 별빛 나침반을 꺼냈어. 이제 어느 길로 가 볼까?",
 "choices": ["빛나는 숲으로 가기", "구름다리 건너기"],
 "shouldEnd": false,
 "endingReason": null
}
```


- `narration`을 **문장 단위로 스트리밍**하여 첫 문장부터 TTS로 전달합니다.
- `choices`는 **최대 2개**의 음성 질문 보조 옵션이며, 아이의 자유 발화가 선택지보다 우선합니다.
- `shouldEnd`와 `endingReason`은 AI 제안값입니다. 시간·침묵·수동 종료는 **애플리케이션 코드가 최종 판정**합니다.
- 위험하거나 과하게 무서운 이야기 흐름은 자극적 묘사 대신 부드러운 모험으로 돌립니다.


### ② 부모 관찰 노트 생성기


입력: 해당 에피소드의 실제 전사·선택 기록.


출력:
- **오늘의 이야기 요약**
- **아이가 한 말 그대로 인용** (실제 기록에 없는 말은 만들지 않기)
- **관찰 한마디** (진단·낙인 없이 사실 중심)
- **안전 검토 플래그** (금지어/위험 표현 등을 조심스럽게 분류하고 필요할 때만 안내)
- **내일 예고** (다음 회차를 기대하게 하는 한 문장)


### ③ 종료 후 기억 요약 + 동화책 다듬기


- `worldMemory`: 재등장 인물, 물건, 관계, 해결된 사건, 다음 회차 연결고리 등의 구조화된 JSON.
- `storybookText`: 어색한 구어 반복을 자연스럽게 다듬은 동화책 본문. **아이의 핵심 아이디어와 선택은 바꾸지 않습니다.**
- `islandTitle` / `episodeTitle`: 섬과 회차의 표시 제목.
- 처리량·응답 시간·추정 비용을 기록합니다. **원본 음성 파일은 저장하지 않습니다.**

## 5. 화면별 경로와 인수 기준


| 경로 | 화면 | 담당 | 통과 조건 |
| --- | --- | --- | --- |
| `/` | 랜딩: 로그인/가입 + `나만의 동화 시작하기` | **4번** | 비회원 첫 이야기로 바로 진입 |
| `/login`, `/signup` | Supabase 매직링크 인증·부모 PIN 설정 | **1번** | 로그인 뒤 부모/아이 모드 선택 가능 |
| `/parent` | 어제 리포트, 원본, 씨앗, 설정, 모드 전환 | **4번** | 실제 저장 데이터와 연결 |
| `/kid` | 세계관 지도·섬·오늘의 동화 버튼 | **4번** | 에피소드 1개당 섬 1개 표시 |
| `/kid/adventure` | 핸즈프리 모험 | **2번** | 마이크 재클릭 없이 여러 턴 대화 가능 |
| `/kid/episodes/[id]` | 동화책 텍스트 + TTS 다시 듣기 | **4번** | 선택한 섬에 해당하는 회차 열람 |
| `/share/[token]` | 비민감 정보만 포함된 공유 카드 | **4번** | 비공개 원문·아이 프로필 노출 금지 |


> **UI 소유권:** 4번은 공통 디자인과 부모·아이 홈·동화책 화면을 맡고, 2번은 `/kid/adventure` 안의 **마이크/음성 상태 UI 및 실제 동작**을 맡습니다. 4번이 `components/kid/`에 만든 공통 컴포넌트를 2번이 가져다 씁니다. **같은 파일 동시 수정 금지.**


**디자인 토큰:** 전날 만든 Canvas의 색상·폰트를 원본으로 삼아 `app/globals.css`의 CSS 변수 또는 공통 토큰 파일에 등록합니다. 이 README에는 원본 색상 코드·폰트명이 없으므로 **임의로 확정하지 말고, 4번이 원본을 확인하여 적용**합니다.

## 8. API 계약 (개발 첫 1시간에 고정)


| Method | Endpoint | 담당 | 동작 |
| --- | --- | --- | --- |
| `POST` | `/api/sessions` | 1 | 게스트/회원 모험 생성 → `worldId`, `episodeId` |
| `POST` | `/api/sessions/claim` | 1 | 로그인 후 현재 게스트 세계관을 보호자 계정으로 귀속 |
| `PATCH` | `/api/sessions/[worldId]/seed` | 1 | 부모가 다음 동화의 씨앗 저장 |
| `POST` | `/api/auth/parent-pin/setup` | 1 | 보호자 PIN 설정·변경 |
| `POST` | `/api/auth/parent-pin/verify` | 1 | 아이→부모 모드 접근 검증 |
| `GET` | `/api/episodes?worldId=...` | 1 | 허가된 세계관의 회차 목록 / 섬 지도 |
| `GET` | `/api/episodes/[id]` | 1 | 해당 회차 동화책·리포트·원본 조회 (권한별 제한) |
| `POST` | `/api/episodes/[id]/complete` | 1 | 해당 회차 마무리, 3번 생성기 호출, 기록·기억 저장 |
| `POST` | `/api/episodes/[id]/next` | 1 | 이전 기억을 이어받은 다음 화 생성 |
| `POST` | `/api/transcribe` | 2 | 녹음 파일 → `text` |
| `POST` | `/api/tts` | 2 | `text` → 음성 스트림/파일 |
| `POST` | `/api/story/turn` | 3 | `episodeId`, `childText` → 문장 이벤트 + 최종 턴 JSON |


### 턴 스트리밍 이벤트 (2번 ↔ 3번 고정)


3번은 `text/event-stream` 형태로 아래의 이벤트를 보냅니다. 문장 이벤트의 수신 순서가 TTS 재생 순서입니다.


```text
event: sentence
data: {"index":0,"text":"우주에 작은 섬이 떠 있었어."}


event: sentence
data: {"index":1,"text":"거기서 누구를 만나고 싶어?"}


event: turn_complete
data: {"choices":["작은 용","별의 요정"],"shouldEnd":false,"endingReason":null}


event: error
data: {"code":"STORY_FAILED","message":"잠깐 쉬었다가 다시 이야기해 보자."}
```


- LLM의 **부분 JSON 문자열을 클라이언트에서 바로 파싱하지 않습니다.** 서버가 완성된 문장과 검증된 결과를 이벤트로 변환합니다.
- 2번은 `sentence`를 받자마자 해당 문장의 TTS를 준비하고, `index` 순서대로 재생합니다.
- 종료 처리 후 `POST /api/episodes/[id]/complete`를 호출합니다. **1번의 완료 API가 서버에서 3번의 `lib/story/` 생성기를 호출하여** 리포트·기억·동화책을 만들고 DB에 기록합니다. 같은 데이터를 서로 다른 API에서 중복 저장하지 않습니다.
- 모든 API는 로그인 세션 또는 유효한 단기 게스트 세션을 검사합니다. **클라이언트가 임의로 보낸 `userId`만 믿지 않습니다.**

## 9. Supabase 스키마 (MVP: 4개 테이블)


아래는 **팀이 공유할 논리 모델**입니다. 실제 컬럼 타입, 인덱스, RLS 정책, 마이그레이션은 **1번이 담당**합니다.


| 테이블 | 주요 필드 | 역할 |
| --- | --- | --- |
| `users` | `id`(Supabase `auth.users` 참조), `parent_pin_hash`, `created_at` | 보호자 계정 프로필·부모 모드 보호 |
| `worlds` | `id`, `owner_user_id`(게스트는 `null`), `guest_token_hash`, `guest_expires_at`, `child_name`, `child_age`, `child_gender`, `child_interests`, `memory_json`, `next_seed`, `created_at` | 한 아이의 세계관과 기억. 게스트→회원 전환 가능 |
| `episodes` | `id`, `world_id`, `episode_number`, `status`, `started_at`, `ended_at`, `end_reason`, `title`, `island_title`, `storybook_text`, `report_json`, `next_teaser` | **에피소드 1개 = 섬 1개** |
| `turns` | `id`, `episode_id`, `turn_index`, `child_text`, `narration`, `choices_json`, `created_at`, `latency_ms` | 실제 아이 발화와 AI 응답의 순서 있는 기록 |


**세계관 기억 JSON 예시**


```json
{
 "characters": ["파란 공룡 토토"],
 "items": ["별빛 나침반"],
 "places": ["달빛 섬"],
 "keyEvents": ["아이는 토토와 함께 길을 잃은 별을 찾아주었다"],
 "nextHook": "다음 섬에서 토토의 친구를 만난다"
}
```


**접근 제어 및 데이터 생명주기**


- 로그인한 사용자는 **자신이 소유한 `worlds`와 하위 `episodes/turns`**에만 접근합니다. Supabase RLS와 서버 측 소유권 검사를 적용합니다.
- 게스트는 무작위 임시 세션 토큰을 **HttpOnly/Secure 쿠키**로 관리하고, DB에는 **토큰 해시만 저장**합니다. 유효기간 후 삭제하도록 설계합니다.
- 게스트가 가입하면 세션 소유권을 검증한 뒤 `worlds.owner_user_id`를 채웁니다. 임의 ID만으로 다른 사람의 세계관을 가져갈 수 없어야 합니다.
- 공유 카드는 **별도 난수 토큰/공유용 응답**으로 제공하고, 원본 발화·리포트·민감한 씨앗을 포함하지 않습니다. 토큰의 폐기/만료를 고려합니다.
- 원본 **오디오 파일은 저장하지 않습니다**. 텍스트 로그만 최소한으로 보관하며, 데모는 성인이 가상 아이 역할을 맡습니다.

## 13. 안전·프라이버시 기본 원칙


1. **해커톤 시연은 가상 아동 정보**로 진행합니다. 실서비스에서 아동 정보를 수집하려면 보호자 동의 등 법적 요건을 먼저 검토해야 합니다.
2. 아이가 무서운 이야기, 위험 행동, 개인정보를 말해도 AI가 이를 확대·강화하지 않도록 스토리 프롬프트와 응답 필터를 설계합니다.
3. **마이크 사용 중 상태**, 종료 버튼, 오류 시 복구 안내를 제공합니다. 녹음 원본을 장기 저장하지 않습니다.
4. 원본 발화·리포트·프로필은 **보호자 계정에서만 조회**할 수 있게 합니다. 아이 화면에는 진단적·민감한 부모 메모를 노출하지 않습니다.
5. 보호자 PIN은 해시 저장·서버 검증·시도 횟수 제한·일시적인 잠금 해제 세션을 사용합니다.
6. LLM을 통한 리포트나 기억 요약이 실패하더라도 **원본 턴 기록 저장이 우선**되도록 설계합니다.


## 14. 시연 완료 기준 (Definition of Done)


### 게스트


- [ ] 새 사용자에게 로그인/회원가입 버튼과 큰 `나만의 동화 시작하기` 버튼이 표시된다.
- [ ] 로그인 없이 1화를 시작하고, AI가 음성으로 이름을 묻는다.
- [ ] 아이가 매 턴 버튼을 누르지 않고 AI와 여러 번 음성으로 주고받는다.
- [ ] 약 5분 후 첫 모험이 끝나고 보호자에게 이어하기/가입을 안내한다.


### 회원·모드


- [ ] 매직링크 로그인/가입이 가능하고 프로필 입력은 선택 사항이다.
- [ ] 부모 PIN을 설정하고, 부모→아이 모드는 바로 전환된다.
- [ ] 아이→부모 모드는 PIN 검증 없이 접근할 수 없다.


### 아이 경험


- [ ] AI가 아이의 자유로운 발화를 동화에 반영한다.
- [ ] 5~10분에 자연스럽게 마무리하고, 10분 상한을 지킨다.
- [ ] `잘래` 발화에 짧게 마무리하고 종료한다.
- [ ] 재생 종료 후 1분 침묵이면 추가 음성 없이 종료·저장한다.
- [ ] 음성 인식 실패 시 선택지 버튼으로 이어갈 수 있다.
- [ ] 에피소드가 끝나면 지도에 **새 섬**이 표시된다.
- [ ] 섬을 누르면 동화책 텍스트를 보고 TTS로 다시 들을 수 있다.
