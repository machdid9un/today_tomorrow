# 상상 무전기 🎙️🌙

> **화면을 바라보지 않고, 아이의 목소리로 만들어 가는 잠자리 모험.**
> 아이는 자기 모험을 만들고, 부모는 묻지 않고 본다.

`상상 무전기`는 아이의 발화에 따라 AI가 이야기를 이어 가는 **오디오 중심 인터랙티브 동화 웹앱**입니다. 대상은 말로 상상을 만들 수 있는 만 4\~9세(유치원·초등 저학년)이고, 첫 공략은 만 5\~7세입니다. 아이는 화면을 거의 조작하지 않고 **핸즈프리 음성 대화**로 5\~10분 모험을 진행합니다. 이야기의 주인공은 귀가 큰 주황색 아기 용 **이야기 용**이고, 아이는 이야기 용과 함께 **작은 별**(행성)을 모험합니다. 부모는 두 가지를 받습니다. 아이가 만든 이야기를 다듬은 **동화책**, 그리고 아이가 이야기 속에서 고른 것과 한 말을 근거로 한 **행동 관찰 리포트**입니다. 완성된 회차는 아이가 고른 **별 안의 장소 하나**로 남고, 다음 회차는 등장인물·물건·사건을 기억합니다.

'상상 무전기'는 제품 이름으로만 남습니다. 이야기 안에는 무전기·탐험대·지직 효과음이 나오지 않습니다.

**돈:** 결제자는 부모. 가족 구독 **월 9,900원**(가설). 무료 = 주 2화 + 리포트 요약 한 줄 + 동화책 / 유료 = 매일 + 마음 담기 + 전체 관찰 리포트. 첫 고객은 설문에 답한 학부모 5명과 그 반 단톡.

**하지 않는 것:** 학습 주입 X · 진단 X · 캐묻기 X · 중독 설계 X. 스토리 엔진은 이야기만 하고 아이를 분석하지 않습니다. 리포트 생성기는 아이의 행동을 추론하되, 모든 추론에 원본(아이가 한 말·고른 선택)을 근거로 붙이고, 원본이 없는 추론은 쓰지 않습니다.

**목표:** 개발 3명(역할 1~4 중 3개를 전담, 1개는 시간 남는 사람이 추가 수행) + 비즈니스 1명이 AI 코딩 에이전트로 **05:00 기능 동결, 08:00 제출**까지 실제로 돌아가는 MVP를 배포·시연합니다.

> **현실적인 범위:** '핸즈프리'는 부모가 시작한 뒤 화면이 켜진 웹앱에서 아이가 매 턴 버튼을 누르지 않고 말하는 방식입니다. 기기 잠금·백그라운드 유지는 보장하지 않습니다. 음성은 `VAD → 발화 단위 녹음 → STT → LLM → TTS`로 구현하며, 실시간 음성 통화는 만들지 않습니다. **환경변수 `VOICE_MODE=handsfree|ptt` 하나로 푸시투토크로 즉시 전환 가능해야 합니다.** 22:00 피벗 게이트에서 VAD·에코가 안 잡히면 코드 재작성이 아니라 플래그 전환으로 대응합니다.

## 0. 뼈대 파일 규칙 (협업 필수)

역할 1이 만든 뼈대 파일과 폴더(7장 구조)는 빈 파일 상태에서 각자 나눠 채웁니다.

- **이름 변경·삭제·이동 금지.** 뼈대에 있는 파일과 폴더의 이름·위치는 그대로 둡니다. 에이전트가 "구조를 정리하자"며 옮기거나 합치려 해도 거절합니다.
- **파일 추가는 허용.** 자기 소유 폴더 안에서라면 새 파일·하위 폴더를 만들어도 됩니다(예: `app/api/auth/parent-gate/route.ts`, `lib/story/prompts.ts`).
- 다른 역할 소유 폴더에 파일을 추가해야 하면 먼저 그 담당자에게 말합니다.
- 뼈대의 이름이 마음에 안 들어도 바꾸지 말고, README의 이름을 따라 씁니다. (예: 섬 → 별로 세계관이 바뀌었지만 DB 컬럼 `island_title`, 컴포넌트 `IslandList`는 이름 그대로 두고 뜻만 "별 안의 장소"로 씁니다.)
- `package.json`, `next.config.*`, `tsconfig.json`, `app/layout.tsx`, `types/`는 역할 1 승인 없이 수정하지 않습니다. (역할 1은 현재 리드가 대행)

## 1. 기술 스택

- 웹: Next.js App Router + TypeScript + Tailwind CSS
- 배포: Vercel (HTTPS 필수 — 마이크 권한)
- DB / 인증: Supabase PostgreSQL + Supabase Auth (이메일 매직링크, 선택 기능)
- 음성 입력: 브라우저 마이크 상시 세션 + VAD → 발화 완료 후 STT API 전송
- 동화 생성: LLM API, 문장 단위 SSE 스트리밍 + 구조화된 턴 결과
- 음성 출력: TTS API, 문장별 재생 큐 (무전기 지직 효과음은 쓰지 않음)
- 협업: GitHub, 기능 브랜치, PR, AI 코딩 에이전트

**공급자 (확정)**
- **LLM:** 래블업 **Token Factory**(OpenAI 호환 API)가 호스팅하는 **DeepSeek** 모델. `lib/story/llm.ts`가 SDK 없이 fetch로 호출하고, 키 등급에서 거부된 모델(403/404)은 사용 가능한 모델 목록에서 가장 비슷한 것으로 한 번 재시도합니다. 턴용(`LLM_STORY_MODEL`)과 노트·기억 요약용(`LLM_REPORT_MODEL`)을 따로 지정할 수 있습니다.
- **STT/TTS:** 지금은 OpenAI(`whisper-1` / `gpt-4o-mini-tts`), **ElevenLabs로 이전 중**(리드 작업). STT 낱말 힌트(keyterms)·맥락 프롬프트·환각 문장 필터는 역할 3이 `lib/story/sttContext.ts`, `lib/story/sttVocab.ts`에 준비해 두었습니다(§5 ⑥).
- 모든 API 키와 Supabase 서비스 롤 키는 서버에서만 사용합니다.

> **매직링크 주의:** Supabase 기본 메일 발송은 시간당 발송 한도가 낮습니다(정확한 값은 프로젝트 설정에서 확인). 심사위원·참가자가 몰리면 메일이 안 갈 수 있으므로, **로그인 없이도 1화 → 2화 → 리포트가 모두 돌아가야 합니다.** 로그인은 "다른 기기에서도, 오래 보관"용입니다.

## 2. 우선순위 (모든 판단의 기준)

**P0 — 없으면 데모 불가 (동결 02:00)**
- 게스트 1화 핸즈프리 루프
- 종료 3조건 (시간·수면 발화·침묵)
- 턴 SSE 스트리밍 + 문장별 TTS 큐
- 자동 저장 (턴 기록이 리포트보다 우선)
- 선택지 버튼 폴백
- 회차 끝 건네주기 화면 → 보호자 결과 화면
- 부모 모드 관문(길게 누르기 + 확인 → 서버 발급 부모 토큰). 리포트·원본 API는 부모 토큰 필수
- 부모 리포트: 요약 + 인용 + 선택 + 근거 붙은 행동 관찰 + 건네볼 한마디 + 내일 예고
- 게스트 2화 기억 (같은 기기 쿠키로 이어가기, 로그인 불필요)
- 회차 완료 즉시 별 안에 장소 1곳(카드 1장) 생성
- 심사용 짧은 회차 `?short=1` (3턴)

**P1 — 점수 올림 (동결 04:00)**
- 오늘의 별 고르기 (행성 4개 지도). 없으면 `themeId` 없이 시작하고 서버가 회차마다 별을 정함
- 내일 이야기에 마음 담기 (4가지 중 하나, 자유 입력은 기본 꺼짐)
- 부모 대시보드 주간 보기 (마음 날씨 · 이번 주 모습 · 인용 카드)
- 동화책 열람 (아이: 듣기 중심 / 부모: 텍스트)
- 요금제 한 줄 + 사전 신청 (이메일 동의)
- 매직링크 로그인 + 게스트 세션 귀속 (다른 기기·장기 보관용)
- 공유 카드 (P1에서 가장 먼저 버릴 후보)

**P2 — 안 되면 버림 (동결 05:00)**
- 부모 PIN (관문을 PIN으로 강화: 설정·검증·잠금)
- 별 지도 위 장소 배치 레이아웃
- 에피소드 TTS 다시 듣기

P0가 흔들리면 P1·P2는 손대지 않습니다. 별 안의 장소는 처음부터 카드 리스트로 만들고, 시간이 남으면 배치만 지도처럼 바꿉니다.

## 3. 서비스 흐름

### A. 처음 방문 (게스트, 로그인 없음)

현실적으로 링크를 처음 여는 사람은 부모이고, 부모가 아이에게 건넵니다. 아이 쪽은 건네받은 순간부터 설정·설명 없이 바로 시작돼야 합니다.

1. 랜딩: 화면 중앙에 **큰 시작 버튼**(문구는 디자인 시안 문구), 우상단에 작게 `로그인`. 버튼 아래 한 줄: "AI가 아이의 말로 이야기를 만들어요. 목소리는 저장하지 않아요."
2. 버튼 → 브라우저 마이크 권한(부모가 허용) → 게스트 세션 생성 → **오늘의 별 고르기**: 아이가 지도에서 행성 4개 중 하나를 고름 → 모험 화면.
3. 이야기 용이 음성으로 첫 인사: **"안녕! 나는 이야기 용이에용. 내 귀가 쫑긋! 네 이름을 알려 줄래용?"** 아이가 음성으로 답변. 이름·나이 입력 화면은 없습니다. 이후 이야기 용은 아이를 이름으로 부릅니다("지우야").
4. 약 **5분** 첫 모험 진행 (`?short=1`이면 3턴).
5. 아이에게 들리는 종료 멘트: **"오늘 이야기는 여기까지예용. 잘 자용, 내일 또 만나용!"** — 가입·결제 언급 없음.
6. 건네주기 화면: 「엄마 아빠에게 건네주세요」 + `보호자 보기` 버튼. 아이 눈앞에 리포트가 바로 뜨지 않게 합니다(특히 글을 읽는 7~9세).
7. `보호자 보기` → 부모 관문 → 보호자 결과 화면: 첫 관찰 리포트 전체 + 동화책 + 오늘 별에 생긴 장소 + "내일 2화가 이어져요" + 내일 이야기에 마음 담기(추천 포함).
8. 같은 기기에서 다음 날 앱을 열면 게스트 쿠키로 2화가 1화를 이어갑니다. 로그인은 결과 화면 하단의 선택 사항: "다른 기기에서도 보려면 이메일로 링크 받기"(= 매직링크 가입 + 사전 신청 동의 선택).

**게스트 규칙:** 가입을 강제하지 않습니다. 게스트 세계는 쿠키가 살아 있는 동안 같은 기기에서 이어집니다(만료 기한 명시). 모험 도중 팝업·가입 유도로 아이를 방해하지 않습니다. 가입·결제 CTA는 아이 화면에 절대 나오지 않고, 아이에게 "엄마한테 사달라고 해" 같은 말도 하지 않습니다.

### B. 회원가입 / 로그인 (선택)
- Supabase Auth 이메일 매직링크 하나. 로그인 비밀번호 없음.
- 선택 입력: 아이 이름, 나이. **성별·관심사는 받지 않습니다.** (스토리에 필수가 아니고, 아동 데이터는 적을수록 좋음)
- 한 계정에 **부모 모드 / 아이 모드**. 아이용 별도 계정은 만들지 않습니다.
- 아이 → 부모 전환은 **부모 관문**(P0: 길게 누르기 + 확인 → 서버가 부모 토큰 발급)으로 막고, PIN은 P2 강화입니다. 화면만 바꿔서는 볼 수 없습니다: 리포트·원문·마음 담기는 부모 토큰이 있을 때만 **서버가 내려줍니다**(권한별 응답 분리).

### C. 부모 모드 (`/parent`) — 부모 대시보드 (디자인 확정)
하단 내비 3개: **마음 리포트 / 이야기 기록 / 설정**.

**마음 리포트** — 탭 `주간` / `하루씩 보기`
- **주간**
  - **마음 날씨**: 요일별 맑음 · 구름 조금 · 흐림 · 비. 이야기 속에서 아이가 한 말만 근거로 하고(근거 인용을 함께 보여 줌), **진단이 아닙니다.**
  - **이번 주에 이런 모습이 보였어요**: 3줄. 줄마다 아이가 한 말·고른 것을 근거로 붙입니다.
  - **인용 카드**: "OO이가 한 말 · 수요일 밤 12화" + 아이 원문 한 줄. `이야기 전체 보기`로 그 회차 기록으로 이동.
- **하루씩 보기**: 회차 하나의 리포트 — 요약 / 아이가 한 말 **그대로 인용** / 고른 것 / 근거 붙은 행동 관찰 / **오늘 건네볼 한마디** 1줄 / 내일 예고 / 오늘 별의 진행.
- **내일 이야기에 마음 담기**: 2×2 선택(용기 북돋기 · 칭찬해주기 · 곁에 있어주기 · 편히 쉬어가기, §5 ③) + CTA **`내일 이야기에 담기`**. 안내 문구: "고른 마음은 용이 내일 이야기 속에서 자연스럽게 전해요. {이름}에게 직접 말하거나 행동을 시키지 않아요." 마음 담기는 아이 화면에 노출되지 않습니다.

**이야기 기록**: 회차별 동화책 + 원본(전사·내레이션·선택 기록).

**설정**: 요금제 한 줄("월 9,900원 · 지금은 무료 체험") + 사전 신청(이메일 동의), 아이 모드로 전환(버튼 한 번) 등. 세부 배치는 디자인 시안을 따릅니다.

**진단 아님**: 성격·심리 단정 표현 금지. 금지 어휘 목록은 `lib/story/reportGenerator.ts`(`FORBIDDEN_TERMS`)에 있고, 코드가 걸러 냅니다.

### D. 아이 모드 (`/kid`)
- **별 지도**: 행성 4개(구름숲 · 물불 · 거꾸로 · 숨은 무지개). 회차를 끝낼 때마다 그 별 안에 **장소 1곳**이 생깁니다(카드: 장소 이름 + 색, DB `island_title`). P2에서 지도 배치.
- **`오늘의 동화 만들기`**(문구는 시안 기준) → 오늘의 별 고르기 → 핸즈프리 모험 시작.
- 장소 선택 → 동화책 열람 (듣기 중심, TTS 다시 듣기는 P2).
- **공유 카드** (`/share/[token]`): 회차 제목 + 별·장소 비주얼 + 삽화 1장. 아이 원문 인용 1줄은 **부모가 카드 생성 시 토글(기본 꺼짐)**. 프로필·마음 담기·리포트는 절대 포함하지 않습니다.

## 4. 음성 모험 핵심 로직

```
부모 마음 담기(선택) → 아이 모드에서 오늘의 동화 시작
 → 오늘의 별 고르기 (themeId: forest | waterfire | upside | rainbow)
 → 이전 회차 기억 + 그 별의 시즌 진행 조회
 → 이야기 용 첫 장면 TTS
 → 마이크 활성화 → VAD로 발화 종료 감지
 → 발화 단위 오디오 → STT (오늘의 별 낱말 힌트)
 → 아이 발화 + 기억 + 별 + 마음 담기 → 스토리 엔진
 → 문장 단위 SSE → 도착 즉시 TTS 큐 → 순서대로 재생
 → 다음 발화 대기 → 반복
 → 종료 조건 → 턴 저장 → 리포트·기억·동화책·시즌 진행 생성
 → 별 안에 장소 1곳 추가
```

### 종료 조건 (코드가 최종 판정, AI는 제안만)
- **5~10분**: 5분 이후 AI가 `shouldEnd`를 제안하면 종료. **10분은 하드 타임아웃**.
- **"잘래", "졸려", "이제 잘 거야"**: 새 전개 없이 짧고 부드러운 마무리 후 종료.
- **1분 무응답**: 잠든 것으로 간주, **추가 TTS 없이** 조용히 종료·저장.
- **부모 수동 종료**: 확인 후 저장. 예외 상황에서도 유실 최소화.
- 마무리 멘트의 마지막 문장은 코드가 고정 멘트("오늘 이야기는 여기까지예용. 잘 자용, 내일 또 만나용!")로 보장합니다.

### 운영 규칙
- 60초 침묵 타이머는 **TTS 재생이 완전히 끝난 뒤** 시작합니다. API 대기·재생 중은 침묵으로 판정하지 않습니다.
- TTS 재생 중에는 마이크 입력을 처리하지 않아 AI 음성이 재인식되지 않게 합니다. 기기별 에코 제거를 테스트합니다.
- STT 실패, 마이크 권한 거부, VAD 오탐 시 **선택지 버튼 폴백**을 표시합니다. 정상 경로는 음성이며 버튼은 예외 처리입니다. 단, 심사위원이 행사장에서 마이크 없이 테스트할 수 있으므로 버튼은 항상 화면에 작게 존재합니다.
- STT가 소음·침묵에서 지어낸 문장("시청해 주셔서 감사합니다" 등)은 서버가 걸러 아이 말로 쓰지 않습니다(`isLikelySttHallucination`).
- 무전기 지직 효과음은 쓰지 않습니다. 시작·전환은 이야기 용의 목소리로만 합니다.
- **지연 목표**: 아이 발화 종료 → 첫 TTS 재생까지 **5초 이내**. 보장치가 아니라 측정치이며 `turns.latency_ms`에 기록합니다.
- 첫 문장 TTS부터 즉시 재생하고 뒤 문장은 순서 보장 큐에 쌓습니다.

### 게스트와 회원의 차이
- 시작: 게스트는 이름을 음성으로 질문 / 회원은 프로필 이름 사용
- 시간: 게스트 약 5분 / 회원 5~10분
- 기억: 게스트는 같은 기기 쿠키가 살아 있는 동안 / 회원은 Supabase 지속 저장(다른 기기 포함)
- 다음 화: 둘 다 세계관·별 진행 이어가기 (게스트는 같은 기기에서만)
- 결과: 둘 다 리포트 + 동화책 + 별 안의 장소 / 회원은 다른 기기에서도 열람

## 5. AI 기능 (역할 3 담당)

스토리 엔진·관찰 노트·기억 요약은 각각 **별도 프롬프트, 별도 호출**입니다. 모두 `lib/story/`에 있고 서버에서만 돕니다.

### ① 스토리 엔진 (`storyEngine.ts`, `prompts.ts`)
입력: 아이 이름·나이(있으면), 오늘의 별과 시즌 진행, 부모 마음 담기(용의 태도), 지난 세계관 기억, 현재 회차 대화, 경과 시간.

출력은 **검증 가능한 턴 구조**:
```json
{
  "narration": "똑똑, 구름 나무 아래 작은 문이 열렸어용. 이 집엔 누가 살고 있을까용?",
  "choices": ["고슴도치", "아기 토끼"],
  "shouldEnd": false,
  "endingReason": null
}
```
- `choices`는 최대 2개(각 12자 이내). 아이의 자유 발화가 선택지보다 우선.
- `shouldEnd`·`endingReason`은 제안값. 시간·침묵·수동 종료는 코드가 판정.

**고정 멘트 (LLM 없이 코드가 보장)**
- 첫 인사: `안녕! 나는 이야기 용이에용. 내 귀가 쫑긋! 네 이름을 알려 줄래용?`
- 마지막 문장: `오늘 이야기는 여기까지예용. 잘 자용, 내일 또 만나용!`

**이야기 용 페르소나 규칙**
- `narration`은 3~4문장(이야기 2~3 + 질문 1), 마지막은 **질문 하나**. 매 턴 이야기가 실제로 한 걸음 나아가야 하고 "그랬구나" 같은 되묻기로 채우지 않습니다. 질문 바로 앞 문장에 소리·빛·모양 단서를 심어 네 살 아이도 한두 단어로 답할 수 있게 합니다.
- 모든 문장을 `~용`으로 끝냅니다(해요체의 '요' → '용': "반가워용!", "누가 그랬을까용?"). 반말 어미와 섞지 않습니다. 아이는 이름으로 가끔 부릅니다("지우야").
- 아이가 한 말을 **낱말 그대로** 이야기 문장에 되살리고 한 걸음 넓힙니다. 아이의 말은 별에 눈에 보이는 변화를 일으키고, 정답은 없습니다.
- 평가·칭찬·정정 금지("잘했어", "멋지다", "틀렸어" X). 이야기로만 받습니다. 연속 질문 금지.
- "몰라"·무응답·아주 짧은 대답: 다그치지 않고 ① 힌트(소리·몸짓 단서) → ② 쉬운 두 가지 보기 → ③ 그래도 어려우면 이야기 용이 먼저 하나 제안하고 아이가 고르게 합니다. 같은 질문은 되풀이하지 않습니다.
- 무섭거나 위험한 흐름은 아이가 고른 방향은 살리고 방식만 안전하게 바꿉니다(무서운 괴물 → 배고픈 아기 괴물, 싸움 → 간지럼·노래 대결).
- **안전 응답**: 아이가 현실에서 맞았다·다쳤다·사라지고 싶다는 말을 하면 이야기로 덮지 않고 먼저 다정하게 받아 줍니다(네 잘못이 아니고, 믿을 수 있는 어른에게 꼭 이야기하기). 개인정보는 묻지 않고, 아이가 말해도 이야기에 넣지 않습니다.
- 아이의 현실(학교·친구·가족·고민)을 묻지 않습니다. 학습·교훈·퀴즈를 주입하지 않습니다.
- "너 AI야?"에는 숨기지 않고 "맞아용, 나는 이야기를 함께 만드는 **AI 이야기 용**이에용"처럼 솔직하게 답한 뒤 이야기로 돌아옵니다.
- 무전기·탐험대·대장님·"치익" 같은 말은 쓰지 않습니다.

**회차 뼈대**: 0턴 첫 인사(고정) → 이름 → (처음 온 별이면 세계관 소개 + 역할) → 단짝 친구가 남은 밤 둘을 알려 주고 아이가 고름 → 곤란 → **3턴째 첫 시도의 뜻밖의 결과**(마음 담기 한 줄, `short`면 2턴째) → 어떻게 → 방해꾼/두 번째 시도 → 마지막 조각 → **7턴 해결 + 얻는 것** → 잠자리 → 마무리 + 고정 멘트. (자세한 턴 표는 ②)

### ② 오늘의 별 — 행성 4종 (`themes.ts`)
별마다 **단짝 친구·방해꾼·밤 목록(`nights`)**이 있습니다. **밤마다 할 일(곤란 → 첫 시도의 뜻밖의 결과 → 진짜 이유 → 해결 → 얻는 것)은 고정**이고, **어느 밤부터 할지는 아이가 고릅니다**(마지막 밤 '결전'만 모든 밤을 끝낸 뒤). 두 밤을 끝낼 때마다 방해꾼이 한 번 나와 가진 것으로 쫓고, 결말의 단서를 하나 흘립니다. 처음 온 별에서는 이름 인사 뒤 **세계관 소개 1~2문장 + 아이의 역할** 한 마디를 들려줍니다.

| `themeId` | 별 | 세계관 (아이에게 하는 말) | 단짝 / 방해꾼 | 밤 (아이가 순서 고름) → 마지막 밤 |
|---|---|---|---|---|
| `rainbow` | 숨은 무지개 | 검은 마왕이 일곱 색깔을 몽땅 빼앗아 온 세상이 회색. 색을 다 섞으면 까매지니 마왕만 새까맣다. **"오늘부터 너는 무지개 용사"** | 알록이(하얀 무지개새) / 까막 졸개 | 빨강 사자(용기 → 동료 합류) · 주황 귤나무(기다려 주기 → 귤) · 노랑 해바라기(웃기기 → 해바라기씨) · 초록 숲(소리로 깨우기 → 덩굴) · 파랑 바다(아기 고래에게 "울어도 돼" → 고래 피리) · 남색 밤하늘(속삭여 별 부르기 → 별빛 조약돌) → **보라: 검은 마왕 결전**, 모은 것을 아이가 골라 쓰고 마왕은 갱생해 밤하늘을 채워 줌 |
| `upside` | 거꾸로 | 뒤죽박죽 마법사가 말을 뒤집어 친구들 말은 반대로 되지만 **아이가 지은 주문은 무엇이든 그대로 통함**(정답 고르기 없음). "거꾸로 주문 마법사" | 뒤뚱이(펭귄) / 뒤죽이(박쥐) | 위로 가는 비 · 천장 침대 · 개미 문 생일 · 거꾸로 그림판 · 메아리(거꾸로 이름) → **뒤죽박죽 마법사**: 모은 주문으로, 마법사가 웃으면 마법이 풀림 |
| `forest` | 구름숲 | 이름을 붙여 주면 구름이 집도 다리도 되는 숲. 이름이 없어 깜깜. "이름 짓기 대장" | 몽글이(구름 양) / 휘잉이(떠돌이 바람) | 아기 새(구름 집) · 반딧불이(구름 길) · 다람쥐(우산 나무) · 시냇물(구름 다리) · 몽글이 생일(케이크) → **큰 바람**: 만든 것들의 이름을 부르면 버팀, 휘잉이에게 이름을 주어 자장가 바람이 됨 |
| `waterfire` | 물불 | 반달 언덕 양쪽의 물방울 마을과 불씨 마을. 서로 좋아하는데 자꾸 엇갈림. "다리 친구" | 똘방이·타닥이 / 쑥덕이(소문 앵무새) | 반달 언덕 · 노래 · 선물 · 아기 불씨 · 김 구름 → **겨울밤**: 불씨는 얼음을 녹이고 물방울은 김 구름으로 불씨를 덮음, 징검돌 다리 완성 |

- 진행은 `worlds.memory_json.planets[별]` = `{ visits, done: [밤 id], collected: [아이가 만든 것], stage }`에 저장합니다(옛 `{stage, collected}` 형식은 읽을 때 변환). 첫 시도 다음 턴까지 가면 그 밤이 `done`에 들어갑니다.
- 회차 뼈대(코드가 턴마다 정함): (0/1) 밤 고르기 → 곤란 → 첫 생각 → **3턴 첫 시도의 뜻밖의 결과** → 4 어떻게 → 5 방해꾼(한 턴 안에서 끝) 또는 두 번째 시도(진짜 이유) → 6 마지막 조각(앞에서 얻은 것·정한 것 다시 쓰기) → **7 해결 + 얻는 것** → 잠. 아이가 일찍 졸려 해도 앞에서 한 말로 한 문장 풀고 재웁니다.
- 턴 API는 `themeId`를 받고(첫 턴에 한 번만 보내도 됨), 회차 동안 `memory_json.activePlanet`에 기억합니다. 안 보내면 episodeId로 고정 선택합니다.
- 같은 설정집을 이야기 프롬프트(`[오늘 밤]` 카드)·STT 낱말 힌트(`docs/stt-vocab-v2.md`)·관찰 노트(별마다 볼 것 / 쓰면 안 되는 해석)가 함께 씁니다.
- 시즌을 다 마친 별은 고전 동화 뼈대(`plotPatterns.ts`)를 그 별의 친구·장소로 옮겨 자유 모험을 합니다.

### ③ 내일 이야기에 마음 담기 (`seedPresets.ts`, 옛 '오늘의 씨앗')
부모는 아이에게 무엇을 시킬지가 아니라 **이야기 용이 어떤 마음으로 곁에 있을지**만 고릅니다.

| 값 | 부모 화면 제목 | 설명 | 이야기 용의 태도 |
|---|---|---|---|
| `courage` | 용기 북돋기 | 용이 할 수 있다고 응원해줘요 | 망설이는 순간 "할 수 있어용, 내가 옆에 있어용". 강요 없이, 다른 길도 늘 열어 둠 |
| `praise` | 칭찬해주기 | 용이 잘한 점을 알아봐 줘요 | 아이 생각이 만든 구체적 변화를 짚어 고마워함. "잘했어"·"착하다" 같은 평가 말은 안 씀 |
| `company` | 곁에 있어주기 | 용이 끝까지 함께 있어 줘요 | 처음부터 끝까지 곁에. 혼자 남거나 헤어지는 장면 없음, 마무리에 나란히 잠듦 |
| `rest` | 편히 쉬어가기 | 조용하고 포근한 이야기로 | 사건·긴장을 줄인 느린 장면, 쉬운 감각 질문, 평소보다 일찍 잠자리로 |

- 고른 마음은 다음 회차 **전체**에서 이야기 용의 태도를 바꿉니다(매 턴 프롬프트 + 3턴째 갈림길 장면에 한 줄).
- 아이에게 무엇을 하라고 시키지 않고, 현실을 묻지 않으며, 아이의 선택이 정답입니다.
- **한 번의 이야기에만** 담깁니다. 갈림길 턴까지 가면 `seedConsumed: true` → complete가 `next_seed_*`를 비웁니다.
- 자유 입력은 **기본 꺼짐**(`ALLOW_CUSTOM_SEED=1`일 때만). 켜면 별도 소형 호출로 판타지 장면 지시문으로 바꾸고, **부모 원문은 스토리 엔진에 들어가지 않습니다.**
- 리포트에 다음 마음 담기 추천(`seedSuggestions`: 아이 말 근거, 방금 쓴 것 제외)을 함께 넣습니다.

### ④ 관찰 노트 생성기 (`reportGenerator.ts`)
입력: 해당 회차의 실제 전사·선택 기록 + 오늘의 별 + 이번에 쓴 마음 담기. 스토리 엔진과 **별도 프롬프트, 별도 호출**. 노트는 표준 해요체(`~용` 말투 X).

출력(`report_json`):
- `summary`: 오늘의 이야기 요약 (2문장)
- `childQuotes`: 아이가 한 말 **그대로 인용** (기록에 없는 말은 코드가 걸러 냄)
- `childChoices`: 아이가 고른 것 (갈림길 포함)
- `observations[]`: `{ inference, evidence[] }` — 행동 관찰 + 근거(아이 발화 원문 조각만). 근거 없는 관찰은 버립니다. `observation`은 하위 호환용으로 이어 붙인 문자열
- `lineForParent`: **오늘 건네볼 한마디** 1문장
- `safetyFlags`: 안전 검토 플래그 (필요할 때만)
- `nextEpisodeTeaser`: 내일 예고 1문장
- `moodWeather`(`sunny` | `partly_cloudy` | `cloudy` | `rainy` = 맑음·구름 조금·흐림·비), `moodNote`, `moodEvidence[]`: 이야기 속에서 아이가 한 말에 드러난 기분. 진단 아님, 근거 인용 필수
- `keywords`: 아이가 자주 쓴 낱말 `{ word, count }[]`
- `planet`: `{ id, planet, done, total, goal, collected }` — 오늘 별의 시즌 진행
- `seedSuggestions`: 다음 마음 담기 추천

금지 어휘(불안·위축·문제·성향·경향 등)가 들어간 관찰은 버리고, 요약·한마디·예고는 안전한 기본 문장으로 바꿉니다. 주간 마음 리포트는 회차별 `report_json`(마음 날씨·관찰·인용)을 모아 보여 줍니다.

### ⑤ 회차 종료 처리 — 기억 요약 + 동화책 + 시즌 진행 (`finalizeEpisode.ts`, `memorySummarizer.ts`)
`finalizeEpisode(episodeId, endReason, themeId?)` → `{ report, summary, errors, seedConsumed, planet }`. 노트와 기억 요약을 병렬로 만들고, 실패해도 턴 기록은 이미 저장돼 있어 재시도할 수 있습니다.
- `summary.worldMemory`: 재등장 인물·물건·장소·사건·다음 연결고리 + `planets`(별별 시즌 진행). 병합 완료본이라 `worlds.memory_json`에 덮어씁니다.
- `summary.storybookText`: 동화책 본문. 서술은 **표준 해요체**(부모가 읽어 줌, `~용`은 용의 대사에만). 아이가 한 말 중 결정·아이디어·이름이 담긴 말 2~3개를 **원문 그대로** 대사로 인용하고, 아이가 하지 않은 말은 아이 대사로 지어내지 않습니다(코드가 검증). **아이의 아이디어와 선택은 바꾸지 않음.**
- `summary.islandTitle`(= 별 안의 장소 이름) / `summary.episodeTitle`.
- `planet`: `{ id, planet, progress, done, total, line, goal }` — 결과 화면용 별 진행.
- 이미 `completed`인 회차에는 다시 호출하지 않습니다(기억이 두 번 병합됨). 처리량·응답 시간·추정 비용 기록. **원본 음성 파일은 저장하지 않음.**

### ⑥ STT 보조 (`sttContext.ts`, `sttVocab.ts`) — 역할 2가 가져다 씀
- `buildSttKeyterms(episodeId, choices, themeId, realtime)`: 화면 보기 + 아이 이름·등장인물 + 오늘의 별 낱말 + 공통 대답 → STT 낱말 힌트 목록(ElevenLabs keyterms용, 실시간은 50개 한도).
- `buildSttPrompt(episodeId, choices, themeId)`: 같은 맥락을 프롬프트 문자열로 (prompt를 받는 STT용).
- `isLikelySttHallucination(text)`: 소음·침묵에서 STT가 지어내는 문장 걸러 내기 (턴 API에서 이미 적용).

### ⑦ 개발 도구 (역할 3)
- `GET /api/story/eval`: **시나리오 30개 자동 채점**(아이 시뮬레이터 + 채점기). 실행·재채점·두 실행 비교.
- `GET /api/story/selftest`: 1화 여러 턴 → 종료(노트·기억·동화책) → 2화 첫 턴을 실제 LLM으로 돌려 JSON으로 돌려줌.
- 두 도구는 **개발 서버 전용**입니다(운영 배포는 404, `STORY_SELFTEST=1`일 때만 켜짐).
- `POST /api/story/finish`: 테스트용 회차 종료 생성(DB 저장 없음, `mock-` episodeId는 메모리 모드로 다음 회차에 이어짐).

### 지연·비용 예산

- 회차당 비용 목표 100원 이하 (TTS가 주 비용). 삽화는 회차당 1장만, 턴마다 생성하지 않음.

## 8. API 계약

- `POST /api/sessions` (1) — 게스트/회원 모험 생성 → `worldId`, `episodeId`
- `POST /api/sessions/claim` (1) — 로그인 후 게스트 세계관을 계정에 귀속
- `PATCH /api/sessions/[worldId]/seed` (1) — 내일 이야기에 마음 담기 저장 `{ preset: "courage" | "praise" | "company" | "rest" | null }`. `custom` + `text`(300자)는 `ALLOW_CUSTOM_SEED=1`일 때만. 입력 검증은 `parseSeedInput`(`lib/story/seedPresets.ts`)
- `GET /api/episodes?worldId=` (1) — 회차 목록 (별 안의 장소 리스트)
- `GET /api/episodes/[id]` (1) — 회차 상세. **모드별 응답 분리**: 아이 모드엔 동화책 텍스트만, 부모 모드(부모 토큰)엔 리포트·원본 포함
- `POST /api/episodes/[id]/complete` (1) — 회차 종료. 서버에서 `finalizeEpisode(episodeId, endReason, themeId?)` 호출 → 리포트·기억·동화책 저장, `seedConsumed`면 `next_seed_*` 비움 (아래 저장 매핑)
- `POST /api/episodes/[id]/next` (1) — 기억을 이어받은 다음 화 생성
- `POST /api/episodes/[id]/share` (1) — 공유 토큰 생성 (`includeQuote` 토글)
- `POST /api/waitlist` (1) — 사전 신청 이메일 (동의 필수)
- `POST /api/auth/parent-pin/setup`, `/verify` (1, P2)
- `POST /api/transcribe` (2) — 오디오 → `text`
- `POST /api/tts` (2) — `text` → 오디오
- `POST /api/story/turn` (3) — 아래 요청 → SSE
- `POST /api/story/finish`, `GET /api/story/eval`, `GET /api/story/selftest` (3) — 테스트·개발 전용 (§5 ⑦)

### 턴 요청 (`POST /api/story/turn`)
```ts
{
  episodeId: string;
  childText: string;   // 첫 호출(turnIndex 0 = 첫 인사)은 ""
  themeId?: "forest" | "waterfire" | "upside" | "rainbow"; // 첫 턴에 한 번만 보내도 회차 동안 기억
  turnIndex?: number;  // 없으면 서버가 저장된 턴 수로 정함
  short?: boolean;     // ?short=1 심사용 3턴
  forceEnd?: boolean;
  latencyMs?: number;  // 직전 턴 지연(prevLatencyMs와 같은 뜻) → turns.latency_ms
}
```
- POST라서 브라우저 `EventSource`로는 못 받습니다. `fetch` + `response.body.getReader()`로 읽습니다.

### 턴 SSE 이벤트 (2 ↔ 3 고정)
```
event: sentence
data: {"index":0,"text":"구름숲 행성에 도착했어용."}

event: sentence
data: {"index":1,"text":"사각사각, 나뭇잎 뒤에 누가 숨어 있을까용?"}

event: turn_complete
data: {"choices":["다람쥐","아기 토끼"],"shouldEnd":false,"endingReason":null}

event: error
data: {"code":"STORY_FAILED","message":"앗, 잘 못 들었어용. 한 번 더 말해 줄래용?"}
```
- 클라이언트는 부분 JSON을 파싱하지 않습니다. 서버가 완성 문장과 검증된 결과만 보냅니다.
- 2번은 `sentence` 수신 즉시 TTS 준비, `index` 순으로 재생.
- 모든 API는 로그인 세션 또는 유효한 게스트 세션을 검사합니다. 클라이언트가 보낸 `userId`만 믿지 않습니다.

### 회차 종료 저장 매핑 (`finalizeEpisode` → complete)
```
worlds.memory_json    ← summary.worldMemory   (병합 완료본, planets 포함 → 덮어쓰기)
worlds.child_name     ← summary.childName     (비어 있을 때만)
worlds.next_seed_*    ← null                  (seedConsumed가 true일 때)
episodes.report_json  ← report
episodes.next_teaser  ← report.nextEpisodeTeaser
episodes.storybook_text / island_title / title ← summary.storybookText / islandTitle / episodeTitle
```

### 접근 제어
- 로그인 사용자는 자기 `worlds`와 하위 데이터만 접근. RLS + 서버 소유권 검사.
- 게스트 토큰은 HttpOnly/Secure 쿠키, DB엔 해시만. 만료 후 삭제.
- 게스트 귀속 시 세션 소유권 검증. 임의 ID로 남의 세계관을 가져갈 수 없음.
- 공유 카드는 별도 난수 토큰. 원본·리포트·마음 담기·프로필 미포함.
- **원본 오디오 미저장.** 텍스트 로그만 최소 보관. 데모는 성인이 가상 아이 역할.

## 13. 안전·프라이버시

1. 시연은 가상 아동 정보로 진행. 실서비스 전 14세 미만 법정대리인 동의 등 법적 요건 검토.
2. 아이가 무서운 이야기·위험 행동·개인정보를 말해도 AI가 확대·강화하지 않도록 프롬프트와 필터 설계. 현실 위험 신호(맞음·다침·사라지고 싶다)는 이야기로 덮지 않고 먼저 받아 준 뒤 믿을 수 있는 어른에게 말하도록 안내하고, 리포트에 안전 플래그로 남김.
3. 마이크 사용 중 상태 표시, 종료 버튼, 오류 복구 안내. 녹음 원본 미저장.
4. 원본 발화·리포트·마음 담기는 보호자 모드(부모 토큰)에서만 조회. 아이 화면에는 서버가 내려주지 않음.
5. 관찰 노트와 마음 날씨는 기록의 정리이지 진단이 아님. 모든 관찰에 아이 원문 근거를 붙임. 스토리 엔진은 분석하지 않고, 노트 생성기는 아이에게 말하지 않음.
6. 이야기 용은 AI임을 숨기지 않음. 아이가 물으면 솔직하게 답함.
7. LLM 리포트·기억 요약이 실패해도 **턴 기록 저장이 우선**.

## 14. 시연 완료 기준 (DoD)

### 게스트 (P0)
- [ ] 랜딩에서 로그인 없이 큰 시작 버튼 → 오늘의 별 고르기 → 바로 시작
- [ ] 이야기 용이 "안녕! 나는 이야기 용이에용. 내 귀가 쫑긋! 네 이름을 알려 줄래용?"으로 이름을 묻고 아이 답변을 받음
- [ ] 매 턴 버튼 없이 여러 번 음성으로 주고받음 (`ptt` 모드면 버튼 1개로)
- [ ] 약 5분 후(`?short=1`이면 3턴) "오늘 이야기는 여기까지예용. 잘 자용, 내일 또 만나용!"으로 끝나고 건네주기 화면 → 부모 관문 → 보호자 화면으로 전환
- [ ] 보호자 화면에 실제 대화 기반 인용·선택·근거 붙은 관찰·한마디·마음 날씨가 표시됨

### 아이 경험 (P0)
- [ ] 자유 발화가 낱말 그대로 이야기에 반영되고, 오늘의 별에 변화가 생김
- [ ] 이야기 용이 끝까지 `~용` 말투로, 평가·칭찬 없이 질문 하나로 턴을 끝냄
- [ ] 이야기 속에 무전기·탐험대·"치익"이 나오지 않음
- [ ] "잘래"에 짧게 마무리
- [ ] 재생 종료 후 1분 침묵이면 추가 음성 없이 종료·저장
- [ ] 음성 실패 시 선택지 버튼으로 진행 가능
- [ ] 발화 끝 → 첫 음성까지 ms가 `turns.latency_ms`에 기록됨 (목표 5초)

### 회원·기억 (P0~P1)
- [ ] 같은 기기에서 2화가 전 회차 캐릭터·물건·사건과 별 진행을 이어받음 (로그인 불필요)
- [ ] 매직링크 로그인, 게스트 회차 귀속
- [ ] 부모 마음 담기가 다음 회차 내내 이야기 용의 태도에 반영되고, 그 회차가 끝나면 비워짐
- [ ] 부모 모드에서 리포트·원본 확인, 아이 모드 API 응답엔 포함되지 않음
- [ ] 회차 완료 시 고른 별 안에 장소 1곳 추가, 시즌 진행 저장 (끝낸 밤 `done` + 아이가 만든 것)
- [ ] 부모 대시보드 주간 보기에 요일별 마음 날씨 · 이번 주 모습 3줄 · 인용 카드 표시
- [ ] 공유 카드에 원문(토글 off 기준)·프로필 미노출
- [ ] 요금제 한 줄과 사전 신청 폼 표시

### 품질·배포

## 15. 에이전트 공통 지시

> 개발을 시작하기 전에 이 README를 끝까지 읽으세요. 당신은 역할 1~4 중 하나를 맡은 담당자입니다. 자신의 소유 폴더와 API 계약을 지키고, 공통 타입·패키지·설정은 역할 1(현재 리드 대행)과 합의 없이 수정하지 마세요. 아직 없는 다른 역할의 API에는 Mock을 쓰되 실제 계약과 동일하게 구현하세요. 모든 기능에서 오류·타임아웃·로딩 상태를 처리하세요. 2장의 우선순위를 따르고, P0가 끝나기 전에는 P1·P2를 시작하지 마세요. 이야기 안에서는 이야기 용(`~용` 말투)과 행성 세계관만 쓰고, 무전기 콘셉트는 쓰지 마세요. 지금 가장 중요한 것은 **`게스트 1화 → 음성 대화 → 자동 종료 → 기록 → 건네주기·부모 관문 → 보호자 화면 리포트 → 같은 기기 2화 기억`** 한 사이클의 통합 시연입니다.
