# 상상 무전기 🎙️🌙

> **아이의 한마디로 모험이 바뀌는, 오디오 중심 인터랙티브 잠자리 동화**

**상상 무전기**는 아이가 직접 말한 내용을 바탕으로 AI가 이야기를 이어 가는 웹 서비스입니다. 부모가 아이의 이름·나이와 선택적인 **이야기 씨앗**을 설정하면, 아이는 큰 마이크 버튼으로 대화에 참여합니다. 4~5번의 대화 후 한 편의 동화가 마무리되고, 다음 화에서는 이전에 등장한 친구·물건·사건을 기억합니다.

**개발 목표:** 4명이 AI 코딩 에이전트를 활용해 **24시간 이내에 실제로 시연 가능한 MVP**를 완성합니다.

> **MVP 범위 안내:** 현재 버전은 **녹음 후 전송(Push-to-talk)** 방식입니다. 동화를 듣는 동안 화면을 볼 필요는 없지만, 매번 말할 때 마이크 버튼을 누르는 방식이므로 완전한 핸즈프리·화면 잠금 상태의 연속 대화는 구현 대상이 아닙니다.

## 1. 핵심 사용자 흐름

```text
[부모: 시작 화면]
  아이 이름 + 나이 + 선택적 이야기 씨앗 입력
            ↓
[아이: 모험 화면]
  큰 마이크 버튼 → 녹음 → STT
            ↓
  LLM이 아이의 말에 따라 다음 장면 생성
            ↓
  생성된 문장을 TTS로 순서대로 재생
            ↻ (아이 발화–AI 응답 4~5회)
            ↓
[부모: 결과 화면]
  관찰 노트 + 내일 예고 + 모험 책 미리보기
  + 요금제 사전 신청 버튼
            ↓
[2화 이어가기]
  고유 링크 → 이전 화 세계관 불러오기 → 새로운 모험
```

## 2. 반드시 구현할 기능 (MVP)

### ① 부모 시작 화면
- 로그인 없이 접속
- 아이 이름 및 나이 입력(필수)
- 부모의 이야기 씨앗 입력(선택): 최근 관심사·함께 이야기하고 싶은 주제
- 시작 버튼 → 세션 생성 → 모험 화면 이동

### ② 아이 모험 화면
- **큰 마이크 버튼 한 개를 중심**으로 한 최소 UI
- 버튼을 이용한 녹음 시작/종료 및 STT 전송
- 아이의 발화를 반영하는 LLM 동화 생성(텍스트 스트리밍)
- 문장이 완성되는 대로 TTS 요청; 생성된 음성을 **순서대로** 재생
- 음성 처리 중 로딩 상태 및 짧은 효과음 표시/재생
- 4~5턴 후 자동으로 따뜻한 결말 생성 및 종료
- 무섭거나 위험한 발화에는 자극적인 전개 대신 안전하게 방향 전환
- 마이크 권한 거부, 인식 실패, API 오류 시 재시도 안내

### ③ 부모 결과 화면
- 오늘의 **관찰 노트**: 아이가 실제로 했던 말과 선택을 사실 중심으로 요약
- **내일 예고**: 다음 화의 소재 또는 후속 장면 한 줄
- **모험 책 미리보기**: 이야기 제목과 텍스트 기반 간단한 페이지 UI
- **요금제 사전 신청**: 이메일을 동의받아 수집하는 폼(결제 없음)

### ④ 2화 이어가기
- 1화에서 사용한 이름, 친구, 물건, 사건, 세계관을 Supabase에 저장
- 추측하기 어려운 고유 링크로 이전 회차를 불러오기
- 이전 화의 기억을 LLM 프롬프트에 반영하여 2화 진행
- 테스트에서는 실제 다음 날을 기다리지 않고 바로 2화를 시작할 수 있도록 구성

## 3. 구현하지 않는 기능 (Scope Out)

- 회원가입 및 정식 부모·자녀 인증 시스템
- 실제 결제 및 구독 연동
- 세계 지도·복잡한 그래픽
- 스트릭·뱃지·출석 보상
- 부모 목소리 복제 또는 커스텀 음성 캐릭터
- 성격 진단·심리 진단·학습 문제
- 화면 잠금 상태의 완전 핸즈프리 실시간 음성 통화

**원칙:** 부가 기능을 추가하는 것보다 `시작 → 말하기 → 듣기 → 종료 → 저장 → 2화 이어가기`의 완성을 우선합니다.

> STT·LLM·TTS의 구체적 모델 및 공급자는 착수 시 팀에서 확정합니다. API 비밀키는 **서버에서만** 사용합니다.

## 5. 팀 역할 분담 (4명)

| 담당 | 책임 | 주요 코드 소유 영역 |
| --- | --- | --- |
| **1번: 백엔드·DB·통합** | Supabase 스키마, 세션 생성, 기억 저장·조회, 고유 링크, 사전 신청, Vercel 배포·PR 통합 | `lib/db/`, `supabase/`, `app/api/sessions/`, `app/api/episodes/`, `app/api/waitlist/` |
| **2번: 음성 시스템** | 모험 화면, 녹음, STT, TTS, 음성 재생 큐, 로딩 효과음, 음성 에러 처리 | `app/adventure/`, `components/voice/`, `app/api/transcribe/`, `app/api/tts/` |
| **3번: AI 동화 엔진** | 동화 프롬프트, LLM 문장 스트리밍, 안전 규칙, 4~5턴 종료, 관찰 노트·내일 예고, 기억 요약 | `lib/story/`, `app/api/story/` |
| **4번: 부모 UI·UX** | 시작 폼, 결과 화면, 모험 책 미리보기, 사전 신청 UI, 모바일 디자인·데모 화면 | `app/page.tsx`, `app/result/`, `components/parent/` |

**공통 규칙**
1. 작업 시작 전에 `types/`의 공통 데이터 타입과 API 요청/응답 형식을 합의합니다.
2. 담당 폴더 밖의 파일은 합의 없이 수정하지 않습니다.
3. `package.json`, 공통 설정, DB 스키마는 **1번이 변경을 조율**합니다.
4. 다른 사람의 API가 미완성인 경우 Mock Data로 화면·로직부터 검증합니다.
5. 기능 구현 후 작은 단위로 PR을 열고, `main`에 병합하기 전에 통합 테스트를 수행합니다.

## 7. API 계약 초안

> 아래 경로와 필드는 **팀 공통 제안 규격**입니다. 개발 첫 1시간에 확정하고 임의로 바꾸지 않습니다.

| 메서드 | 경로 | 담당 | 핵심 기능 |
| --- | --- | --- | --- |
| `POST` | `/api/sessions` | 1번 | 이름·나이·씨앗 입력 → `episodeId`, `shareToken` 반환 |
| `POST` | `/api/transcribe` | 2번 | 오디오 파일 → `text` 반환 |
| `POST` | `/api/story/turn` | 3번 | `episodeId`, `childText`, `turnIndex` → 이야기 문장 스트림 |
| `POST` | `/api/tts` | 2번 | `text` → 재생 가능한 오디오 데이터 |
| `POST` | `/api/story/finish` | 3번 | 누적 대화 → 결말·관찰 노트·예고·기억 요약 생성 및 저장 |
| `GET` | `/api/episodes/[token]` | 1번 | 고유 링크 토큰으로 이전 화·기억 조회 |
| `POST` | `/api/episodes/[token]/next` | 1번 | 이전 기억을 이어받아 2화 세션 생성 |
| `POST` | `/api/waitlist` | 1번 | 동의받은 이메일 사전 신청 저장 |

**LLM 스트리밍 이벤트 예시:** `sentence`(완성된 문장), `complete`(이번 AI 응답 종료), `error`(오류). 2번은 `sentence` 이벤트를 받으면 TTS를 요청하고 **순서가 보장되는 재생 큐**로 출력합니다. 3번은 턴 수가 종료 조건에 도달하면 결말을 생성합니다.

## 8. DB 데이터 모델 초안

- `story_worlds`: 세계관 ID, 아이 표시 이름, 나이, 선택적 이야기 씨앗, 접근 토큰 해시, 생성일
- `episodes`: 회차 ID, 세계관 ID, 회차 번호, 진행 상태, 동화 제목, 요약, 관찰 노트, 내일 예고, 세계관 기억(JSON)
- `story_turns`: 회차 ID, 턴 순서, 아이가 말한 텍스트, AI가 생성한 텍스트
- `waitlist`: 이메일, 수집 동의 여부, 등록일

**세계관 기억 예시:**

```json
{
  "characters": ["파란 공룡 토토"],
  "objects": ["별빛 나침반"],
  "last_event": "토토가 잃어버린 별을 찾았다",
  "next_hook": "토토에게 새로운 친구가 찾아온다"
}
```

> 음성 원본 파일은 MVP에서 저장하지 않습니다. 개인의 민감한 고민이나 실제 아동의 음성·신상정보는 데모에 사용하지 않습니다.

## 9. 로컬 실행 방법

```bash
npm install
cp .env.example .env.local
npm run dev
```

브라우저에서 `http://localhost:3000`에 접속합니다.

`.env.example`에 둘 **환경변수 이름 예시** (실제 값은 절대 커밋하지 않음):

```dotenv
OPENAI_API_KEY=
SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=
APP_BASE_URL=http://localhost:3000
```

- OpenAI 외 다른 공급자를 쓸 경우 팀이 정한 STT·LLM·TTS 키로 대체합니다.
- `SUPABASE_SERVICE_ROLE_KEY` 및 모든 AI 비밀키는 서버에서만 사용합니다.
- `.env`, `.env.local` 등은 `.gitignore`에 포함합니다.
- Supabase는 공개 쓰기 권한을 열지 말고 서버 API를 통해 접근합니다.

## 11. 24시간 개발 일정

| 시간 | 목표 |
| --- | --- |
| **0~1시간** | 역할·API 계약·DB 모델 합의, 레포지토리 설정 |
| **1~5시간** | 4명 병렬 개발, Mock Data 사용 |
| **5~8시간** | **1차 통합: 녹음 → STT → LLM → TTS 성공** |
| **8~13시간** | 시작 → 모험 → 결과 → DB 저장까지 연결 |
| **13~17시간** | 2화 이어가기 및 세계관 기억 테스트 |
| **17~20시간** | 모바일 사용성·오류·보안 기본 점검 |
| **20~24시간** | 배포, 발표 자료, 데모 리허설 및 백업 시연 준비 |

## 12. 데모 성공 기준 (Definition of Done)

- [ ] 부모가 로그인 없이 가상 아이의 이름·나이·이야기 씨앗을 입력한다.
- [ ] 아이 역할의 발표자가 마이크로 말하고 STT 결과를 얻는다.
- [ ] AI가 입력 내용을 반영해 자연스럽게 다음 장면을 만든다.
- [ ] 생성된 문장이 TTS로 차례대로 들린다.
- [ ] 4~5턴 후 동화가 자동 마무리된다.
- [ ] 부모 결과 화면에 실제 대화 기반 관찰 노트·내일 예고가 표시된다.
- [ ] 동화책 미리보기와 사전 신청 폼이 보인다.
- [ ] 공유 링크에서 1화 기억을 불러오고 2화에 반영한다.
- [ ] 마이크 접근 거부·API 실패 시 사용자에게 안내가 표시된다.
- [ ] 배포된 Vercel URL에서 전체 시연 흐름이 작동한다.

## 13. 안전 및 개인정보 원칙

- **해커톤 시연은 성인이 아이 역할을 수행하고 가상 정보만 사용합니다.** 실제 어린이 대상 서비스 전에는 법정대리인 동의, 연령 적합성, API 제공자의 아동 데이터 요구사항 등을 별도로 충족해야 합니다.
- 관찰 노트는 **발언과 선택의 기록**이지, 심리·성격 진단이 아닙니다.
- 폭력적·공포스러운 요청은 아이에게 적절한 수준으로 부드럽게 전환합니다.
- 로그인 없는 링크는 인증 대체 수단이 아니므로 **충분히 긴 무작위 토큰**, 서버 측 조회 권한 검증, 검색 엔진 노출 방지를 적용합니다. 링크를 받은 사람이 기록을 볼 수 있다는 한계를 시연용으로 명확히 합니다.
- API 키는 서버 환경변수에 보관하며, 사전 신청 이메일은 명시적 동의를 받은 뒤 저장합니다.
