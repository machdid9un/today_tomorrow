# 상상 무전기 🎙️🌙

> **화면을 바라보지 않고, 아이의 목소리로 만들어 가는 잠자리 모험.**
> 아이는 자기 모험을 만들고, 부모는 묻지 않고 본다.

`상상 무전기`는 아이의 발화에 따라 AI가 이야기를 이어 가는 **오디오 중심 인터랙티브 동화 웹앱**입니다. 아이는 화면을 거의 조작하지 않고 **핸즈프리 음성 대화**로 5~10분 모험을 진행합니다. 부모는 하나의 계정에서 아이가 이야기 속에서 고른 것과 한 말을 **해석 없이 그대로** 보고, 다음 이야기의 씨앗을 넣습니다. 완성된 회차는 **섬**으로 저장되고, 다음 회차는 등장인물·물건·사건을 기억합니다.

**돈:** 결제자는 부모. 가족 구독 **월 9,900원**(가설). 무료 = 주 2화 + 공유 카드 / 유료 = 매일 + 씨앗 + 관찰 노트. 첫 고객은 설문에 답한 학부모 5명과 그 반 단톡.

**하지 않는 것:** 학습 주입 X · 진단 X · 캐묻기 X · 중독 설계 X. AI는 이야기만 하고, 노트는 기록을 정리할 뿐 아이를 분석하지 않는다.

**목표:** 개발 3명(역할 1~4 중 3개를 전담, 1개는 시간 남는 사람이 추가 수행) + 비즈니스 1명이 AI 코딩 에이전트로 **05:00 기능 동결, 08:00 제출**까지 실제로 돌아가는 MVP를 배포·시연합니다.

> **현실적인 범위:** '핸즈프리'는 부모가 시작한 뒤 화면이 켜진 웹앱에서 아이가 매 턴 버튼을 누르지 않고 말하는 방식입니다. 기기 잠금·백그라운드 유지는 보장하지 않습니다. 음성은 `VAD → 발화 단위 녹음 → STT → LLM → TTS`로 구현하며, 실시간 음성 통화는 만들지 않습니다. **환경변수 `VOICE_MODE=handsfree|ptt` 하나로 푸시투토크로 즉시 전환 가능해야 합니다.** 22:00 피벗 게이트에서 VAD·에코가 안 잡히면 코드 재작성이 아니라 플래그 전환으로 대응합니다.

## 1. 기술 스택

- 웹: Next.js App Router + TypeScript + Tailwind CSS
- 배포: Vercel (HTTPS 필수 — 마이크 권한)
- DB / 인증: Supabase PostgreSQL + Supabase Auth (이메일 매직링크)
- 음성 입력: 브라우저 마이크 상시 세션 + VAD → 발화 완료 후 STT API 전송
- 동화 생성: LLM API, 문장 단위 SSE 스트리밍 + 구조화된 턴 결과
- 음성 출력: TTS API, 문장별 재생 큐 + 짧은 무전기 지직 효과음
- 협업: GitHub, 기능 브랜치, PR, AI 코딩 에이전트

STT/LLM/TTS 공급자·모델은 **20:30까지** 확정합니다. 래블업 바우처로 가능한 축부터 확인합니다. 모든 API 키와 Supabase 서비스 롤 키는 서버에서만 사용합니다.

## 2. 우선순위 (모든 판단의 기준)

**P0 — 없으면 데모 불가 (동결 02:00)**
- 게스트 1화 핸즈프리 루프
- 종료 3조건 (시간·수면 발화·침묵)
- 턴 SSE 스트리밍 + 문장별 TTS 큐
- 자동 저장 (턴 기록이 리포트보다 우선)
- 선택지 버튼 폴백
- 부모 리포트: 인용 + 선택 + 관찰 한마디 + 건네볼 한마디 + 내일 예고
- 2화 기억 (전 회차 캐릭터·물건·사건 재등장)

**P1 — 점수 올림 (동결 04:00)**
- 매직링크 로그인 + 게스트 세션 귀속
- 부모 씨앗 저장 (프리셋 5개 + 자유 입력)
- 섬 카드 리스트
- 공유 카드
- 요금제 한 줄 + 사전 신청 (이메일 동의)

**P2 — 안 되면 버림 (동결 05:00)**
- 부모 PIN (설정·검증·잠금)
- 섬 "지도" 레이아웃
- 에피소드 TTS 다시 듣기

P0가 흔들리면 P1·P2는 손대지 않습니다. 섬은 처음부터 카드 리스트로 만들고, 시간이 남으면 배치만 지도처럼 바꿉니다.

## 3. 서비스 흐름

### A. 처음 방문 (게스트, 로그인 없음)
1. 랜딩: 화면 중앙에 큰 **`무전기 켜기`**, 우상단에 작게 `로그인`.
2. 버튼 → 게스트 세션 생성 → 모험 화면.
3. AI가 음성으로 **"이름이 뭐야?"** 질문, 아이가 음성으로 답변.
4. 약 **5분** 첫 모험 진행.
5. 아이에게 들리는 종료 멘트: **"오늘 무전은 여기까지. 내일 또 만나."** — 가입 언급 없음.
6. 종료 후 화면은 **보호자용 결과 화면**으로 전환: 관찰 노트 미리보기 + "내일 이어가려면 이메일로 링크 받기". 이 이메일 입력이 매직링크 가입이자 사전 신청입니다. 가입하면 게스트 회차를 계정에 귀속합니다.

**게스트 규칙:** 가입을 강제하지 않습니다. 임시 세션이며 보호자 등록 전에는 장기 보관을 보장하지 않습니다. 모험 도중 팝업·가입 유도로 아이를 방해하지 않습니다. 가입 CTA는 아이 화면에 절대 나오지 않습니다.

### B. 회원가입 / 로그인
- Supabase Auth 이메일 매직링크 하나. 로그인 비밀번호 없음.
- 선택 입력: 아이 이름, 나이. **성별·관심사는 받지 않습니다.** (스토리에 필수가 아니고, 아동 데이터는 적을수록 좋음)
- 한 계정에 **부모 모드 / 아이 모드**. 아이용 별도 계정은 만들지 않습니다.
- 부모 PIN(아이→부모 전환 보호)은 **P2**입니다. PIN이 없어도 안전한 이유: 아이 모드의 API 응답에는 리포트·원문·씨앗이 **서버에서 내려오지 않습니다**(권한별 응답 분리). 화면만 바꿔서는 볼 수 없습니다.

### C. 부모 모드 (`/parent`)
- **어제의 교신 일지**: 이야기 요약 / 아이가 한 말 **그대로 인용** / 아이가 고른 선택 / 관찰 한마디(사실만, "~을 골랐어요" 수준) / **오늘 건네볼 한마디** 1줄 / 내일 예고.
- **진단 아님**: 성격·심리 단정 표현 금지. 금지 어휘 목록을 3번 프롬프트에 둡니다.
- **오늘의 씨앗**: 프리셋 5개(친구 / 학원·학교 / 동생 / 무서운 것 / 새로운 곳) + 자유 입력. 씨앗은 아이 화면에 노출되지 않습니다.
- **원본 열람**: 회차별 전사·내레이션·선택 기록.
- **요금제 한 줄**: "월 9,900원 · 지금은 무료 체험" + 사전 신청(이메일 동의).
- 아이 모드로 전환: 버튼 한 번.

### D. 아이 모드 (`/kid`)
- **섬 리스트**: 완료 회차마다 섬 카드 1장(제목 + 색). P2에서 지도 배치.
- **`오늘의 동화 만들기`** → 핸즈프리 모험 시작.
- 섬 선택 → 동화책 텍스트 열람 (TTS 다시 듣기는 P2).
- **공유 카드** (`/share/[token]`): 회차 제목 + 섬 비주얼 + 삽화 1장. 아이 원문 인용 1줄은 **부모가 카드 생성 시 토글(기본 꺼짐)**. 프로필·씨앗·리포트는 절대 포함하지 않습니다.

## 4. 음성 모험 핵심 로직

```
부모 씨앗(선택) → 아이 모드에서 오늘의 동화 시작
 → 이전 회차 세계관 기억 조회
 → AI 첫 장면 TTS
 → 마이크 활성화 → VAD로 발화 종료 감지
 → 발화 단위 오디오 → STT
 → 아이 발화 + 세계관 + 씨앗 → 스토리 엔진
 → 문장 단위 SSE → 도착 즉시 TTS 큐 → 순서대로 재생
 → 다음 발화 대기 → 반복
 → 종료 조건 → 턴 저장 → 리포트·기억·동화책 생성
 → 다음 날 섬 추가
```

### 종료 조건 (코드가 최종 판정, AI는 제안만)
- **5~10분**: 5분 이후 AI가 `shouldEnd`를 제안하면 종료. **10분은 하드 타임아웃**.
- **"잘래", "졸려", "이제 잘 거야"**: 새 전개 없이 짧고 부드러운 마무리 후 종료.
- **1분 무응답**: 잠든 것으로 간주, **추가 TTS 없이** 조용히 종료·저장.
- **부모 수동 종료**: 확인 후 저장. 예외 상황에서도 유실 최소화.

### 운영 규칙
- 60초 침묵 타이머는 **TTS 재생이 완전히 끝난 뒤** 시작합니다. API 대기·재생 중은 침묵으로 판정하지 않습니다.
- TTS 재생 중에는 마이크 입력을 처리하지 않아 AI 음성이 재인식되지 않게 합니다. 기기별 에코 제거를 테스트합니다.
- STT 실패, 마이크 권한 거부, VAD 오탐 시 **선택지 버튼 폴백**을 표시합니다. 정상 경로는 음성이며 버튼은 예외 처리입니다. 단, 심사위원이 행사장에서 마이크 없이 테스트할 수 있으므로 버튼은 항상 화면에 작게 존재합니다.
- 지직 효과음은 시작·전환 시 짧고 작게. 취침을 방해할 만큼 반복하지 않습니다.
- **지연 목표**: 아이 발화 종료 → 첫 TTS 재생까지 **5초 이내**. 보장치가 아니라 측정치이며 `turns.latency_ms`에 기록합니다.
- 첫 문장 TTS부터 즉시 재생하고 뒤 문장은 순서 보장 큐에 쌓습니다.

### 게스트와 회원의 차이
- 시작: 게스트는 이름을 음성으로 질문 / 회원은 프로필 이름 사용
- 시간: 게스트 약 5분 / 회원 5~10분
- 기억: 게스트 임시 세션 / 회원 Supabase 지속 저장
- 다음 화: 게스트는 종료 후 보호자 화면에서 가입 안내 / 회원은 세계관 이어가기
- 결과: 게스트는 노트 미리보기 / 회원은 부모 리포트 + 원본 + 섬 생성

## 5. AI 기능 세 가지 (3번 담당)

### ① 스토리 엔진
입력: 아이 이름·나이(있으면), 부모 씨앗(장면 지시문으로 변환된 것), 지난 세계관 기억, 현재 회차 대화, 경과 시간.

출력은 **검증 가능한 턴 구조**:
```json
{
  "narration": "토토가 별빛 나침반을 꺼냈어. 이제 어느 길로 가 볼까?",
  "choices": ["빛나는 숲으로 가기", "구름다리 건너기"],
  "shouldEnd": false,
  "endingReason": null
}
```
- `narration`은 2~3문장, 문장 단위로 스트리밍. 반드시 열린 질문 1개 또는 선택지 2개로 끝남.
- `choices`는 최대 2개. 아이의 자유 발화가 선택지보다 우선.
- `shouldEnd`·`endingReason`은 제안값. 시간·침묵·수동 종료는 코드가 판정.
- 아이의 답을 평가·칭찬·판단하지 않고 이야기로만 받습니다. 연속 질문 금지.
- 무섭거나 위험한 흐름은 자극적 묘사 대신 부드러운 모험으로 전환.

### ② 씨앗 변환
- 부모가 고른 프리셋(친구 / 학원·학교 / 동생 / 무서운 것 / 새로운 곳)마다 **장면 지시문을 미리 작성**합니다. 예: 친구 → "중반에 동료를 두고 가야 하는 갈림길 장면을 1회 넣어라. 그 장면에서 아이에게 현실을 묻지 말 것."
- 자유 입력 씨앗은 별도 소형 호출로 장면 지시문으로 변환합니다. **부모 원문은 스토리 엔진에 들어가지 않습니다.**
- 씨앗 장면은 회차당 1회, 3턴째에 배치. 아이 반응이 무엇이든 이야기는 그냥 진행.

### ③ 관찰 노트 생성기
입력: 해당 회차의 실제 전사·선택 기록. 스토리 엔진과 **별도 프롬프트, 별도 호출**.

출력:
- 오늘의 이야기 요약 (2문장)
- 아이가 한 말 **그대로 인용** (기록에 없는 말은 만들지 않음)
- 아이가 고른 선택 (씨앗 장면 포함)
- 관찰 한마디: "~을 골랐어요 / ~라고 말했어요" 수준. 금지 어휘(불안·위축·문제·성향·경향 등) 사용 금지. 진단·낙인 없음.
- **오늘 건네볼 한마디**: 부모가 아이에게 말할 수 있는 문장 1개
- 안전 검토 플래그 (필요할 때만)
- 내일 예고 1문장

### ④ 종료 후 기억 요약 + 동화책 다듬기
- `worldMemory`: 재등장 인물·물건·장소·사건·다음 연결고리 JSON.
- `storybookText`: 구어 반복을 다듬은 동화책 본문. **아이의 아이디어와 선택은 바꾸지 않음.**
- `islandTitle` / `episodeTitle`.
- 처리량·응답 시간·추정 비용 기록. **원본 음성 파일은 저장하지 않음.**

### 지연·비용 예산
- 음성 왕복 5초. 턴당 출력 80토큰 이하.
- 회차당 비용 목표 100원 이하 (TTS가 주 비용). 삽화는 회차당 1장만, 턴마다 생성하지 않음.

## 6. 역할 분담 (개발 3명 + 비즈니스 1명)

개발 역할은 4개로 유지합니다. 3명이 하나씩 전담하고, **역할 4(UI/UX)는 전담자 없이 시간이 남는 사람이 추가로 맡습니다.** 역할 4의 작업은 P1 이하 비중이 크므로 P0가 끝난 사람이 가져갑니다.

### 역할 1 — 백엔드·DB·인증·통합 (리드)
- 20:30까지 Next.js + Supabase + Vercel 뼈대 배포, GitHub 레포, 브랜치 규칙
- 스키마 `users / worlds / episodes / turns`, 마이그레이션, RLS
- 매직링크 로그인, 게스트 세션 토큰(HttpOnly 쿠키, DB엔 해시), 게스트 → 회원 귀속
- `/api/sessions`, `/api/episodes`, `/api/auth`(P2 PIN)

## 8. API 계약 (20:30까지 고정)

- `POST /api/sessions` (1) — 게스트/회원 모험 생성 → `worldId`, `episodeId`
- `POST /api/sessions/claim` (1) — 로그인 후 게스트 세계관을 계정에 귀속
- `PATCH /api/sessions/[worldId]/seed` (1) — 부모 씨앗 저장
- `GET /api/episodes?worldId=` (1) — 회차 목록 (섬 리스트)
- `GET /api/episodes/[id]` (1) — 회차 상세. **모드별 응답 분리**: 아이 모드엔 동화책 텍스트만, 부모 모드엔 리포트·원본 포함
- `POST /api/episodes/[id]/complete` (1) — 회차 종료. 서버에서 3번 생성기 호출 → 리포트·기억·동화책 저장
- `POST /api/episodes/[id]/next` (1) — 기억을 이어받은 다음 화 생성
- `POST /api/episodes/[id]/share` (1) — 공유 토큰 생성 (`includeQuote` 토글)
- `POST /api/waitlist` (1) — 사전 신청 이메일 (동의 필수)
- `POST /api/auth/parent-pin/setup`, `/verify` (1, P2)
- `POST /api/transcribe` (2) — 오디오 → `text`
- `POST /api/tts` (2) — `text` → 오디오
- `POST /api/story/turn` (3) — `episodeId`, `childText` → SSE

### 턴 SSE 이벤트 (2 ↔ 3 고정)
```
event: sentence
data: {"index":0,"text":"우주에 작은 섬이 떠 있었어."}

event: sentence
data: {"index":1,"text":"거기서 누구를 만나고 싶어?"}

event: turn_complete
data: {"choices":["작은 용","별의 요정"],"shouldEnd":false,"endingReason":null}

event: error
data: {"code":"STORY_FAILED","message":"잠깐 쉬었다가 다시 이야기해 보자."}
```
- 클라이언트는 부분 JSON을 파싱하지 않습니다. 서버가 완성 문장과 검증된 결과만 보냅니다.
- 2번은 `sentence` 수신 즉시 TTS 준비, `index` 순으로 재생.
- 모든 API는 로그인 세션 또는 유효한 게스트 세션을 검사합니다. 클라이언트가 보낸 `userId`만 믿지 않습니다.

## 9. Supabase 스키마 (4개 테이블)

- `users` — `id`(auth.users 참조), `parent_pin_hash`(P2), `created_at`
- `worlds` — `id`, `owner_user_id`(게스트는 null), `guest_token_hash`, `guest_expires_at`, `child_name`, `child_age`, `memory_json`, `next_seed_preset`, `next_seed_text`, `created_at`
- `episodes` — `id`, `world_id`, `episode_number`, `status`, `started_at`, `ended_at`, `end_reason`, `title`, `island_title`, `storybook_text`, `report_json`, `next_teaser`, `share_token_hash`, `share_include_quote`
- `turns` — `id`, `episode_id`, `turn_index`, `child_text`, `narration`, `choices_json`, `latency_ms`, `created_at`
- `waitlist` — `email`, `consent`, `created_at`

성별·관심사 컬럼은 없습니다.

### 접근 제어
- 로그인 사용자는 자기 `worlds`와 하위 데이터만 접근. RLS + 서버 소유권 검사.
- 게스트 토큰은 HttpOnly/Secure 쿠키, DB엔 해시만. 만료 후 삭제.
- 게스트 귀속 시 세션 소유권 검증. 임의 ID로 남의 세계관을 가져갈 수 없음.
- 공유 카드는 별도 난수 토큰. 원본·리포트·씨앗·프로필 미포함.
- **원본 오디오 미저장.** 텍스트 로그만 최소 보관. 데모는 성인이 가상 아이 역할.

## 13. 안전·프라이버시

1. 시연은 가상 아동 정보로 진행. 실서비스 전 14세 미만 법정대리인 동의 등 법적 요건 검토.
2. 아이가 무서운 이야기·위험 행동·개인정보를 말해도 AI가 확대·강화하지 않도록 프롬프트와 필터 설계.
3. 마이크 사용 중 상태 표시, 종료 버튼, 오류 복구 안내. 녹음 원본 미저장.
4. 원본 발화·리포트·씨앗은 보호자 모드에서만 조회. 아이 화면에는 서버가 내려주지 않음.
5. 관찰 노트는 기록의 정리이지 진단이 아님. 스토리 엔진은 분석하지 않고, 노트 생성기는 아이에게 말하지 않음.
6. LLM 리포트·기억 요약이 실패해도 **턴 기록 저장이 우선**.
